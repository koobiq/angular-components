### Corner cases

Depending on the content requirements, a button can take the following width values:

Hug — the button width depends on the length of the text inside and equals the text width plus the side paddings up to the button edges.

<Example id="button-hug-content" />

Fixed — the button width is fixed and does not depend on the length of the text. If the text does not fit, it is truncated with an ellipsis. Do not forget about the inner paddings.

<Example id="button-fixed-content" />

Fill — the button adapts to the width of the block it is placed in. If the width of the block changes (for example, of a modal window), the width of the button changes too. The text inside such a button behaves the same way as in Fixed.

<Example id="button-fill-content" />
