Кнопка запускает действие. Атрибут `kbq-button` добавляют к нативному элементу `<button>`, а если кнопка ведёт на другую страницу — к `<a>`.

### Стиль и цвет

Внешний вид кнопки задают два входа: стиль `kbqStyle` (`KbqButtonStyles`) и цвет `color` (`KbqComponentColors`). Стилей три: `filled` (по умолчанию), `outline` и `transparent`. У каждого из них два своих цвета:

| `kbqStyle`              | `color`                                      |
| :---------------------- | :------------------------------------------- |
| `filled` (по умолчанию) | `contrast`, `contrast-fade` (по умолчанию)   |
| `outline`               | `theme-fade`, `contrast-fade` (по умолчанию) |
| `transparent`           | `theme`, `contrast` (по умолчанию)           |

Если `color` не задан, кнопка берёт цвет своего стиля по умолчанию и меняет его вместе со стилем. Сочетание, которого нет в таблице, тоже отображается цветом стиля по умолчанию. Статусных цветов (`success`, `warning`, `error`) у кнопки нет.

### Содержимое

Кнопка содержит текст, иконки или и то и другое. Чтобы поставить иконку перед текстом, добавьте ей директиву `kbqButtonPrefix`, после текста — `kbqButtonSuffix`: сторону определяет директива, а не порядок в разметке. Иконка рядом с текстом без этих директив тоже работает, но тогда текст, который не умещается, обрезается без многоточия.

<Example id="button-content" />

Если в кнопке только иконки — одна или две, — она автоматически оформляется как кнопка-иконка: с одной иконкой это квадрат 32 × 32px. Иконка декоративна, поэтому задайте такой кнопке доступное имя через `aria-label` или `aria-labelledby`. Для кликабельной иконки без контейнера кнопки используйте [Icon Button](/ru/components/icon-button).

### Размеры

| Параметр             | Значение                        |
| :------------------- | :------------------------------ |
| Высота               | 32px                            |
| Ширина кнопки-иконки | 32px с одной иконкой            |
| Текст                | Text Normal Medium              |
| Иконка               | L (16px)                        |
| Перенос строк        | Нет: текст всегда в одну строку |

### Ширина

В зависимости от содержимого ширина кнопки задаётся одним из трёх способов.

Hug — поведение по умолчанию: ширина кнопки равна ширине содержимого плюс боковые отступы, но не больше ширины контейнера.

<Example id="button-hug-content" />

Fixed — ширина задаётся в CSS и не зависит от длины текста. Если текст не умещается, он обрезается многоточием. Учитывайте боковые отступы по 12px: они входят в ширину кнопки.

<Example id="button-fixed-content" />

Fill — кнопка растягивается на ширину контейнера (`width: 100%`) и меняется вместе с ним, например при изменении ширины модального окна. Текст ведёт себя так же, как у Fixed.

<Example id="button-fill-content" />

### Индикация загрузки

Если обработка действия занимает больше 1–2 секунд, покажите, что система работает: добавьте кнопке класс `kbq-progress`. Класс сочетается с любым стилем, цветом и состоянием. Он только рисует индикатор и не блокирует кнопку, поэтому повторный запуск действия предотвращайте в своём коде.
