Clamped List компактно отображает длинные списки, скрывает элементы за заданным лимитом и позволяет развернуть содержимое полностью.

### Раскрывающийся список

По умолчанию показывается 10 элементов, остальные скрываются. Если в скрытой части меньше 6 элементов, то показываем весь список. Эти параметры при необходимости можно изменить.

### Сворачивание по переполнению

По умолчанию список сворачивается по количеству: видимыми остаются `collapsedVisibleCount` элементов, остальные скрываются. Чтобы сворачивать по размеру контейнера, задайте `mode="overflow"` — компонент измерит контейнер и скроет элементы, которые в него не помещаются.

Сворачивание по переполнению предъявляет свои требования:

- Перебирайте весь сигнал `items()` и регистрируйте каждый элемент по числовому индексу: `[kbqOverflowItem]="$index"`. Нужна одна директива на элемент и индексы от 0 до `items.length - 1`, иначе список вернётся к сворачиванию по количеству.
- Контейнер должен быть ограничен по оси переполнения (например, фиксированной шириной), а при вертикальной ориентации — по высоте. Без ограничения переполнения не возникнет.
- `orientation` задаёт ось измерения, `wrap="wrap"` позволяет списку переноситься на несколько строк.
- На сервере (SSR) геометрии нет, поэтому отрисовывается запасной вариант по количеству с `collapsedVisibleCount`.
- `hiddenThreshold` работает как обычно: если скрыто меньше элементов, чем порог, список не сворачивается. `scrollOnCollapse` управляет прокруткой контейнера списка в видимую область после сворачивания.

Потребителям на NgModule нужно импортировать `KbqOverflowItemsModule` вместе с `KbqClampedTextModule`. Потребителям на standalone — добавить в `imports` компонента две директивы из примера: `KbqOverflowItem` и `KbqOverflowItemsResult`.

### Доступность

Переключатель вы размещаете сами, поэтому директиву `kbqClampedListTrigger` на него нужно поставить вручную: без неё переключатель не будет доступен с клавиатуры, а скринридер не сообщит, свёрнут список или развёрнут.

Собственных отступов у переключателя нет: он размещается вместе со списком.

> Вкладка API этой страницы общая с **Clamped text**: оба компонента поставляются из точки входа `@koobiq/components/clamped-text` и делят директиву-триггер, контракт `KbqClampedRoot` и секцию локали.
