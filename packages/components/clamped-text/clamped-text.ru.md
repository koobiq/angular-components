Компонент **Clamped Text** помогает аккуратно показать длинный текст. В свернутом виде он оставляет только заданное число строк, а при разворачивании показывает весь текст.

### Количество строк

По умолчанию текст обрезается после 5 строк. Атрибут `rows` задает, сколько строк показывать в свернутом виде:

```html
<kbq-clamped-text [rows]="3">
    In a distributed denial-of-service attack (DDoS attack), the incoming traffic flooding the victim originates from
    many different sources. More sophisticated strategies are required to mitigate this type of attack; simply
    attempting to block a single source is insufficient as there are multiple sources.
</kbq-clamped-text>
```

### Одна строка не сворачивается

Если скрытая часть содержит всего одну строку, компонент показывает её сразу. Кнопка «Развернуть» не появляется, потому что текст уже занимает ту же высоту, что и свернутая часть с кнопкой.

### Управление состоянием извне

Входной параметр `isCollapsed` позволяет управлять состоянием компонента из родительского контекста — например, из параметров маршрута. Это двустороннее связывание, поэтому `[(isCollapsed)]` держит родителя в актуальном состоянии:

`isCollapsedChange` сообщает **только о действии пользователя**: он срабатывает при нажатии на переключатель и никогда — при собственном измерении компонента или как эхо значения, которое вы записали сами. Поэтому привязка к параметру маршрута безопасна: загрузка страницы ничего не записывает.

### Входные параметры

| Параметр           | Тип                    | По умолчанию | Описание                                                                                                                        |
| ------------------ | ---------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `rows`             | `number`               | `5`          | Сколько строк остаётся в свернутом виде. Переключатель появляется, только если содержимое длиннее `rows + 1` строк.             |
| `isCollapsed`      | `boolean \| undefined` | —            | Состояние сворачивания. `undefined` означает, что компонент решает сам: сворачивает, как только содержимое не помещается.       |
| `debounceTime`     | `number`               | `0`          | Задержка перед повторным измерением после изменения размера, в миллисекундах. Чем она больше, тем позже появится переключатель. |
| `scrollOnCollapse` | `boolean`              | `true`       | Прокручивать ли компонент обратно в область просмотра при сворачивании. `false` — сворачивать строго на месте.                  |

`isCollapsedChange` — выходная половина двустороннего связывания `[(isCollapsed)]`.

### Свой переключатель

`kbq-clamped-text` рисует собственный переключатель, поэтому обычно ничего добавлять не нужно. Директива `kbqClampedListTrigger`, которую он использует внутри, экспортируется и сама задаёт семантику раскрытия — `role="button"`, `tabindex="0"`, `aria-expanded` и `aria-controls` на свернутую область. Прописывать эти атрибуты вручную не нужно.
