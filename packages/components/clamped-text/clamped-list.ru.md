Clamped List компактно отображает длинные списки, скрывает элементы за заданным лимитом и позволяет развернуть содержимое полностью.

### Раскрывающийся список

По умолчанию показывается 10 элементов, остальные скрываются. Если в скрытой части меньше 6 элементов, то показываем весь список. Эти параметры при необходимости можно изменить.

<!-- example(clamped-list-overview) -->

Элементы списка могут быть строчными. Для компактности используется короткая надпись в кнопке разворачивания.

<!-- example(clamped-list) -->

Многострочный список с точкой по центру в качестве разделителя. Надпись в текстовой кнопке пишется с заглавной буквы.

### Входные параметры

`kbqClampedList` — директива: поставьте её на элемент-обёртку списка и читайте видимый срез через ссылку в шаблоне (`#list="kbqClampedList"`).

| Параметр                | Тип       | По умолчанию | Описание                                                                                      |
| ----------------------- | --------- | ------------ | --------------------------------------------------------------------------------------------- |
| `items`                 | `T[]`     | `[]`         | Полный список. В шаблон выводится `visibleItems()`.                                           |
| `collapsedVisibleCount` | `number`  | `10`         | Сколько элементов остаётся видимыми в свернутом виде.                                         |
| `hiddenThreshold`       | `number`  | `6`          | Сколько элементов должно быть скрыто, чтобы имело смысл показывать переключатель.             |
| `isCollapsed`           | `boolean` | `true`       | Состояние сворачивания, двусторонняя привязка `[(isCollapsed)]`. Выход — `isCollapsedChange`. |

Члены только для чтения, доступные в шаблоне:

| Член                    | Тип           | Описание                                                                  |
| ----------------------- | ------------- | ------------------------------------------------------------------------- |
| `visibleItems()`        | `T[]`         | Срез для отрисовки: усечённый в свернутом виде и полный в развернутом.    |
| `exceededItemCount()`   | `number`      | Сколько элементов скрыто в свернутом виде.                                |
| `hasToggle()`           | `boolean`     | Достаточно ли скрыто элементов, чтобы рисовать переключатель.             |
| `showMoreCountText()`   | `string`      | Локализованная надпись «показать ещё» с уже подставленным числом.         |
| `localeConfiguration()` | строки локали | `openText`, `closeText`, `showMoreText` и `moreText` для активной локали. |

`moreText` — вспомогательная строка для короткой надписи на переключателе («ещё 25»); сама директива её не отрисовывает.

### Свой переключатель

Переключатель размещаете вы, но делать его доступным вручную не нужно: поставьте на него `kbqClampedListTrigger`, и директива сама задаст `role="button"`, `tabindex="0"`, `aria-expanded` и `aria-controls` на список. Прописывать эти атрибуты руками не нужно, и не стоит обходиться голым `<a>` без директивы — именно `kbqClampedListTrigger` превращает элемент в управление раскрытием.

<!-- prettier-ignore -->
```html
<div #list="kbqClampedList" kbqClampedList [items]="items">
    @for (item of list.visibleItems(); track item) {
        <span>{{ item }}</span>
    }

    @if (list.hasToggle()) {
        <a kbq-link kbqClampedListTrigger pseudo>
            {{ list.isCollapsed() ? list.showMoreCountText() : list.localeConfiguration().closeText }}
        </a>
    }
</div>
```

Собственных отступов у переключателя нет — размещайте его вместе со списком, как любой другой элемент.

> Вкладка API этой страницы общая с **Clamped text**: оба компонента поставляются из точки входа `@koobiq/components/clamped-text`, потому что делят директиву-триггер, контракт `KbqClampedRoot` и одну секцию локали.
