A slider selects a numeric value or range. It suits approximate adjustments with immediate visual feedback. A numeric input can accompany the slider when an exact value matters.

<Example id="slider-overview" />

Drag a thumb, click the track or use the keyboard to change the value. The 32-pixel interaction area extends beyond the visible track.

### When to use a slider

Use a slider for quick adjustments within known bounds. Show the selected value beside the track when it matters to the decision. In the scan settings, each schedule has its own concurrency limit.

<Example id="slider-settings" />

### Step and bounds

`min` and `max` bound the scale; `step` defines a positive step anchored at `min`. Defaults are 0, 100 and 1. Fractional values are supported. The greatest selectable value lies on the step grid: with `min=0`, `max=10`, `step=3`, it is 9.

External values are clamped and snapped for display. Changing inputs alone does not emit `valueCommit`. A non-positive or non-finite step falls back to 1; `max < min` collapses the scale to a single point.

### States

`invalid` indicates an error, for example when validity depends on another form field. In Angular forms, `ErrorStateMatcher` controls when errors appear. `disabled` prevents changes and removes thumbs from the focus sequence. `readonly` allows focus and reading the value while preventing changes.

<Example id="slider-states" />

### Track marks

`marks` adds marks and optional captions. Marks do not change the step. With `step=null`, only mark values are selectable; without marks, only `min` is available. Clicking a caption selects its value; the caption itself does not receive focus.

<Example id="slider-marks" />

Categorical values can use numeric indexes with text labels and `displayWith`. For a non-linear numeric scale, `scale` supplies mutually inverse monotonic `toPosition` and `toValue` functions: a position is a fraction from 0 to 1. Step and thumb separation always use value units.

### Range

A range value is a pair `[start, end]`. Each thumb has an individual accessible name through `thumbLabels`. Clicking the track moves the nearest thumb. `minDistance` defines the minimum separation in value units; excessive separation is limited to the available scale.

`collision` controls how thumbs interact:

- `none` stops the thumb at its neighbour; this is the default.
- `swap` changes the active range boundary when a thumb crosses its neighbour.
- `push` moves the neighboring thumb while preserving minimum separation.

<Example id="slider-range" />

The strategy applies to pointer, keyboard and numeric input. Tab order stays lower bound first, then upper bound. With `swap`, focus follows the moving thumb.

### Vertical layout

`vertical` displays a vertical scale. Values increase from bottom to top; `reversed` reverses the scale.

<Example id="slider-vertical" />

### Range fill

The default fill extends from the start of the scale to the value, or between the bounds of a pair. `fill="end"` highlights values above a threshold; `fill="outside"` highlights values outside a selected range. `fill="none"` hides the fill.

<Example id="slider-fill" />

`fill="origin"` fills from `fillOrigin` to the value. The default origin is 0, suitable for audio balance or another parameter with positive and negative values.

### Form field

The component supports `[(value)]`, reactive forms and `[(ngModel)]`. A `kbq-form-field` wrapper associates labels, hints and errors with the thumbs. For ranges, `thumbLabels` identifies the purpose of each bound.

<Example id="slider-forms" />

### Committing a change

`valueChange` reports the live value. `valueCommit` contains `value` and `source`: `pointer`, `keyboard` or `input`. It fires only when the value changed, after pointer release, key release or the end of numeric editing. Holding a key produces one completion event. Use `valueCommit` for expensive external updates while the thumb continues to move immediately.

Esc, pointer cancellation and lost capture restore the value from the start of the gesture without `valueCommit`. Leaving focus completes a keyboard change. Programmatic writes and Angular form resets do not emit `valueCommit`. `name` includes the value in HTML form data; ranges use `name[0]` and `name[1]`.

Dragging scales the map preview. Releasing the thumb redraws the tiles at the selected zoom level.

<Example id="slider-commit" />

### Value tooltip

`showTooltip` shows the value immediately on focus and after a short delay on hover. The tooltip stays visible during a drag. Press <kbd>Esc</kbd> or move focus away to dismiss it. Vertical sliders show it beside the thumb. Use `displayWith` to format the value.

<Example id="slider-tooltip" />

### Thumb alignment

The default `thumbAlignment="contain"` keeps thumbs inside the control. `thumbAlignment="center"` centres each thumb on the selected point, requiring extra space outside the scale endpoints.

<Example id="slider-alignment" />

### Label and selected value

Boundary labels and the current value can be placed beside the scale. `aria-labelledby` or `aria-label` supplies the accessible name. For values with units, `displayWith` also formats the value text exposed to screen readers.

<Example id="slider-labels" />

### Slider and input

`kbq-input-slider` combines a numeric field with a slider along its bottom edge. It accepts the same values, bounds and collision strategies as `kbq-slider`. The numeric field provides exact adjustments; the thumb provides quick changes.

Place the numeric field beside the slider when both controls fit. Use `kbq-input-slider` for a compact layout. A range has a separate editor for each bound.

<Example id="slider-input" />

Intermediate text, including an empty field, is preserved during editing. On <kbd>Enter</kbd> or blur, the field displays the snapped valid value; an empty field restores the last selected value. Number formatting and separators follow the Koobiq locale. Esc cancels the field edit.

### Accessibility

Use `kbq-label` inside `kbq-form-field`. Clicking the label focuses the thumb or the first numeric field. Give each range thumb a distinct `thumbLabels` entry, such as “Minimum price” and “Maximum price”. Use `displayWith` for times, percentages and other quantities so screen readers announce the unit with the value.

### Keyboard interaction

Each thumb participates in the normal Tab sequence. Disabled thumbs are skipped; read-only thumbs remain focusable.

| Key                                 | Action                                               |
| ----------------------------------- | ---------------------------------------------------- |
| <kbd>Esc</kbd>                      | Cancels the current change and hides the tooltip     |
| <kbd>→</kbd>, <kbd>↑</kbd>          | Increases the value by one step                      |
| <kbd>←</kbd>, <kbd>↓</kbd>          | Decreases the value by one step                      |
| <kbd>Home</kbd>                     | Selects the lowest available value                   |
| <kbd>End</kbd>                      | Selects the highest available value                  |
| <kbd>PgUp</kbd>, <kbd>PgDn</kbd>    | Changes the value by `pageStep` steps, 10 by default |
| <kbd>Shift</kbd> + <kbd>arrow</kbd> | Changes the value by `pageStep` steps                |

`reversed` reverses arrows while retaining the numeric meaning of Home, End, PgUp and PgDn. With `step=null`, arrows move between marks. Standard text editing commands in the numeric field are preserved.
