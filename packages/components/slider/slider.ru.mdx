Слайдер — ползунок для выбора числового значения или диапазона. Он подходит для приблизительной настройки с мгновенной визуальной обратной связью. Для точного значения слайдер можно дополнить числовым полем.

<Example id="slider-overview" />

Значение меняется при перетаскивании бегунка, нажатии на шкалу или управлении с клавиатуры. Область управления высотой 32 пикселя шире видимой шкалы.

### Когда использовать

Слайдер подходит для быстрой настройки в известном диапазоне. Покажите выбранное значение рядом со шкалой, если оно влияет на решение пользователя. В настройках сканирования у каждого расписания свой лимит параллельных проверок.

<Example id="slider-settings" />

### Шаг и ограничения

`min` и `max` ограничивают шкалу, `step` задаёт положительный шаг от `min`. По умолчанию используются 0, 100 и 1. Дробные значения поддерживаются. Наибольшее доступное значение лежит на сетке шага: при `min=0`, `max=10`, `step=3` это 9.

Внешнее значение ограничивается границами и округляется для отображения. Само по себе изменение входных параметров не вызывает `valueCommit`. Неположительный или нечисловой шаг заменяется на 1; при `max < min` шкала сводится к одной точке.

### Состояния

`invalid` показывает ошибку, например когда допустимость значения зависит от другого поля формы. В Angular-формах момент появления ошибки определяет `ErrorStateMatcher`. Состояние `disabled` запрещает изменение и исключает бегунки из последовательности фокуса. Состояние `readonly` сохраняет фокус и чтение значения, но запрещает изменение.

<Example id="slider-states" />

### Отметки на шкале

`marks` добавляет отметки и необязательные подписи. Отметки не меняют шаг. При `step=null` выбирать можно только значения из `marks`; без отметок доступно только `min`. Нажатие на подпись выбирает соответствующее значение, сама подпись не получает фокус.

<Example id="slider-marks" />

Для категориальных значений можно использовать индексы с текстовыми подписями и `displayWith`. Для числовой нелинейной шкалы `scale` задаёт взаимно обратные монотонные функции `toPosition` и `toValue`: позиция выражается числом от 0 до 1. Шаг и расстояние между бегунками всегда задаются в единицах значения.

### Диапазон

Значение диапазона — пара `[start, end]`. Каждый бегунок имеет собственное доступное имя через `thumbLabels`. Нажатие на шкалу перемещает ближайший бегунок. `minDistance` задаёт минимальное расстояние в единицах значения; слишком большое расстояние ограничивается доступной шкалой.

Свойство `collision` определяет поведение при столкновении:

- `none` — бегунок останавливается у соседнего; используется по умолчанию.
- `swap` — при пересечении меняется активная граница диапазона.
- `push` — бегунок сдвигает соседний, сохраняя минимальное расстояние.

<Example id="slider-range" />

Стратегия применяется при работе указателем, с клавиатуры и в числовом поле. Порядок перехода по Tab остаётся от нижней границы к верхней. При `swap` фокус следует за перемещаемым бегунком.

### Вертикальный формат

`vertical` располагает шкалу вертикально. Значение увеличивается снизу вверх; `reversed` меняет направление шкалы.

<Example id="slider-vertical" />

### Заливка диапазона

По умолчанию заливка идёт от начала шкалы до значения, а для пары — между границами. `fill="end"` подсвечивает значения выше порога, `fill="outside"` — область вне выбранного диапазона. `fill="none"` скрывает заливку.

<Example id="slider-fill" />

`fill="origin"` заполняет шкалу от `fillOrigin` до значения. Начало по умолчанию — 0: такой вариант подходит для баланса звука или другого параметра с положительными и отрицательными значениями.

### Поле в форме

Компонент поддерживает `[(value)]`, реактивные формы и `[(ngModel)]`. Обёртка `kbq-form-field` связывает с бегунками подпись, подсказку и ошибку. Для диапазона `thumbLabels` уточняет назначение каждой границы.

<Example id="slider-forms" />

### Событие завершения изменения

`valueChange` сообщает текущее значение. `valueCommit` содержит `value` и `source`: `pointer`, `keyboard` или `input`. Событие возникает только при изменении значения: после отпускания указателя, отпускания клавиши или окончания числового ввода. Удержание клавиши даёт одно событие завершения. Для затратных внешних обновлений подходит `valueCommit`, пока положение бегунка обновляется непрерывно.

Esc, отмена указателя и потеря захвата возвращают значение к началу жеста без `valueCommit`. Уход фокуса завершает клавиатурное изменение. Программная запись и сброс Angular-формы не вызывают `valueCommit`. Параметр `name` добавляет значение в данные HTML-формы; для диапазона используются имена `name[0]` и `name[1]`.

При перетаскивании меняется масштаб карты. Когда пользователь отпускает бегунок, пример перерисовывает тайлы для выбранного масштаба.

<Example id="slider-commit" />

### Значение во всплывающей подсказке

`showTooltip` показывает значение сразу при фокусе и после короткой задержки при наведении. Подсказка остаётся открытой при перетаскивании. Клавиша <kbd>Esc</kbd> и уход фокуса скрывают её. У вертикальной шкалы подсказка появляется сбоку. Текст задаёт `displayWith`.

<Example id="slider-tooltip" />

### Выравнивание бегунков

По умолчанию `thumbAlignment="contain"` удерживает бегунки внутри границ контрола. `thumbAlignment="center"` центрирует бегунок на выбранной точке, поэтому на концах шкалы требуется свободное место снаружи.

<Example id="slider-alignment" />

### Подпись и выбранное значение

Подписи границ и текущее значение можно разместить рядом со шкалой. Доступное имя задаётся через `aria-labelledby` или `aria-label`. Для величин с единицами измерения `displayWith` формирует также текст значения, доступный скринридеру.

<Example id="slider-labels" />

### Ползунок и поле ввода

`kbq-input-slider` объединяет числовое поле и шкалу на его нижней границе. Он принимает те же значения, ограничения и стратегии столкновения, что и `kbq-slider`. Числовое поле подходит для точной настройки, бегунок — для быстрого изменения.

Поставьте числовое поле рядом со слайдером, если для двух контролов хватает места. При компактной компоновке используйте `kbq-input-slider`. Для диапазона он показывает отдельное поле на каждую границу.

<Example id="slider-input" />

Во время ввода сохраняется промежуточный текст, в том числе пустое поле. По <kbd>Enter</kbd> или при уходе фокуса поле показывает округлённое допустимое значение; пустое поле возвращается к последнему выбранному значению. Числовой формат и разделители следуют локали Koobiq. Esc отменяет изменение в поле.

### Доступность

Используйте `kbq-label` в составе `kbq-form-field`. Клик по подписи переводит фокус на бегунок или первое числовое поле. Для отдельных бегунков диапазона укажите `thumbLabels`, например «Минимальная цена» и «Максимальная цена». Для времени, процентов и других величин с единицами передайте `displayWith`, чтобы скринридер озвучивал значение целиком.

### Управление с клавиатуры

Каждый бегунок входит в обычную последовательность перехода по Tab. Заблокированный бегунок её пропускает, бегунок только для чтения принимает фокус.

| Клавиша                               | Действие                                                  |
| ------------------------------------- | --------------------------------------------------------- |
| <kbd>Esc</kbd>                        | Отменяет текущее изменение и скрывает подсказку           |
| <kbd>→</kbd>, <kbd>↑</kbd>            | Увеличивает значение на один шаг                          |
| <kbd>←</kbd>, <kbd>↓</kbd>            | Уменьшает значение на один шаг                            |
| <kbd>Home</kbd>                       | Выбирает наименьшее доступное значение                    |
| <kbd>End</kbd>                        | Выбирает наибольшее доступное значение                    |
| <kbd>PgUp</kbd>, <kbd>PgDn</kbd>      | Изменяет значение на `pageStep` шагов, по умолчанию на 10 |
| <kbd>Shift</kbd> + <kbd>стрелка</kbd> | Изменяет значение на `pageStep` шагов                     |

`reversed` меняет направление стрелок, но сохраняет числовой смысл Home, End, PgUp и PgDn. При `step=null` стрелки переходят между отметками. Стандартные команды изменения текста в числовом поле сохраняются.
