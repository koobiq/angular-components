### Styling

The `--kbq-slider-*` CSS custom properties control thumb size and shape, track thickness and colors. The examples show a wide track, round range thumbs and a solid round thumb.

<Example id="slider-custom" />

| CSS property                       | Purpose             |
| ---------------------------------- | ------------------- |
| `--kbq-slider-thumb-width`         | Thumb width         |
| `--kbq-slider-thumb-height`        | Thumb height        |
| `--kbq-slider-thumb-radius`        | Thumb corner radius |
| `--kbq-slider-track-size`          | Track thickness     |
| `--kbq-slider-track-hover`         | Track hover color   |
| `--kbq-slider-fill-hover`          | Fill hover color    |
| `--kbq-slider-thumb-pressed-scale` | Pressed thumb scale |
