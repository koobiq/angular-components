### Стилизация

Размер и форма бегунка, толщина шкалы и цвета задаются CSS-переменными `--kbq-slider-*`. Ниже показаны широкая шкала, круглые бегунки диапазона и сплошной круглый бегунок.

<Example id="slider-custom" />

| CSS-переменная                     | Что меняет                 |
| ---------------------------------- | -------------------------- |
| `--kbq-slider-thumb-width`         | Ширина бегунка             |
| `--kbq-slider-thumb-height`        | Высота бегунка             |
| `--kbq-slider-thumb-radius`        | Радиус скругления          |
| `--kbq-slider-track-size`          | Толщина шкалы              |
| `--kbq-slider-track-hover`         | Цвет шкалы при наведении   |
| `--kbq-slider-fill-hover`          | Цвет заливки при наведении |
| `--kbq-slider-thumb-pressed-scale` | Масштаб нажатого бегунка   |
