#### Input field example

An input inside `kbq-select-matcher`. `[useDefaultHandlers]="false"` turns off the tree select's own click, keyboard and focus handlers, which would otherwise toggle the panel on every click and swallow `Space` and `Enter` typed into the input. The example opens the panel and passes the keys to it by itself.

#### No available options

A tree select is intended to have available choices. If it has no nodes, this should be treated as an exceptional case — when the application does not
provide any choices, the control should be replaced with an input field or a dialog for creating a new entity.

As a last resort, a message can be placed in the panel through `<kbq-select-no-options>`, the same directive the plain select reads. The empty
`kbq-tree-selection` in the example is load-bearing: without one the tree-select never resolves its options, and the panel refuses to open — the
message would never be seen.

#### Custom scroll strategy

Override the scroll strategy via `KBQ_SELECT_SCROLL_STRATEGY`. `KbqAutoHideScrollStrategy` (from `@koobiq/components/core`) stops repositioning once
the trigger scrolls out of view and emits on `hide`, so you can close the panel yourself.

#### Smart search

Search splits a multi-word query into parts and searches for them independently, trims leading and trailing spaces, is case-insensitive, and folds diacritics. The algorithm is described in the [Smart search guide](/en/other/search-smart).
