#### Нет вариантов выбора

Tree select предполагает наличие вариантов выбора. Если в нём нет узлов, то это надо рассматривать как исключительную ситуацию. Когда приложение не
предлагает варианты выбора, контрол следует заменить на поле ввода или на диалог создания новой сущности.

На крайний случай можно разместить сообщение в панели через `<kbq-select-no-options>` — ту же директиву, что читает обычный селект. Пустая
`kbq-tree-selection` в примере — не формальность: без неё tree-select не разрешает свои опции, и панель не открывается — сообщение никто бы не
увидел.

<Example id="tree-select-no-variants" />

#### Кастомная стратегия прокрутки

Стратегию прокрутки можно переопределить через токен `KBQ_SELECT_SCROLL_STRATEGY`. `KbqAutoHideScrollStrategy` (из `@koobiq/components/core`)
останавливает изменение позиции, как только триггер выходит за пределы видимости, и генерирует событие в `hide` — подпишитесь на него, чтобы закрыть
панель самостоятельно.
