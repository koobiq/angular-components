#### Триггер внутри поля

`kbq-time-range-title-as-control` помещает триггер внутрь `kbq-form-field`, поэтому у периода появляются
подпись, подсказка и стили ошибки обычного поля. `kbqTimeRangeTitlePlaceholder` оформляет текст,
который показывается при отсутствии значения, — чтобы это состояние вообще было достижимо, задайте
`[nonNullable]="false"`.

### Ограничение выбора

Доступна настройка минимальной и максимальной даты через `minDate` и `maxDate`.

Оба ограничения учитывают не только дату, но и время. Если задать `maxDate` на 31 декабря без времени, выбрать получится только полночь — чтобы был доступен весь день, укажите время 23:59.

Ограничения показаны в окне выбора: рядом с вариантом «Период», а когда предустановок нет — под полем «по».

### Передача предустановок через DI

Список вариантов и сами варианты — это данные, поэтому заменить можно и то, и другое, не трогая шаблон:

- `KBQ_DEFAULT_TIME_RANGE_TYPES` заменяет список вариантов по умолчанию (`defaultTimeRangeTypes`) для
  всех `kbq-time-range` ниже провайдера. `[availableTimeRangeTypes]` переопределяет его для конкретного
  компонента.
- `KBQ_CUSTOM_TIME_RANGE_TYPES` регистрирует варианты, которых нет во встроенном списке. Каждая запись
  содержит идентификатор, длительность (`units`) и единицу, в которой форматируется подпись
  (`translationType`), либо фиксированный `range` вместо длительности.

```ts
providers: [
    {
        provide: KBQ_CUSTOM_TIME_RANGE_TYPES,
        useValue: [{ type: 'last3Weeks', units: { weeks: -3 }, translationType: 'weeks' }]
    },
    { provide: KBQ_DEFAULT_TIME_RANGE_TYPES, useValue: ['lastHour', 'last3Weeks', 'range'] }
];
```

### Пустое значение и коррекция значения

`nonNullable` (по умолчанию `true`) определяет, что означает `null`, записанный через форм-контрол.
Пока он `true`, `null` заменяется первым доступным вариантом и триггер всегда показывает период;
установите `false`, чтобы компонент мог оставаться без значения и показывать плейсхолдер.

`valueCorrected` срабатывает, когда компоненту пришлось изменить полученное значение: тип отсутствует
в `availableTimeRangeTypes`, у `range` нет одной из границ или пришел `null` при `nonNullable`.
Событие отдает исправленное значение, чтобы хост мог записать его обратно, и молчит, если значение уже
совпадает с тем, которое построил бы компонент.

Входы, выход и их значения по умолчанию перечислены на вкладке API.
