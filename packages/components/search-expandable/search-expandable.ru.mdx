Поле поиска, которое разворачивается из компактной кнопки-иконки.

Компонент является элементом формы и не имеет отдельного входного параметра для значения: привяжите его через `[formControl]`, `[formControlName]` или `[(ngModel)]`, иначе при инициализации будет выброшена ошибка. Введённое значение попадает в связанный контрол через `emitValueTimeout` миллисекунд или по нажатию `Enter`, если задан `isEmitValueByEnterEnabled`.

Кнопка с крестиком и клавиша `Escape` очищают непустое значение, оставляя поиск развёрнутым и сохраняя фокус в поле ввода; если поле пустое, они сворачивают поиск.
