**Autocomplete** показывает подходящие варианты в раскрывающемся списке по мере ввода. Значение можно выбрать, не вводя его целиком.

### Поиск

Добавление `createSearchPredicate` в фильтрацию вариантов включает [умный поиск](/ru/other/search-smart). В таком режиме поиск обрабатывает слова запроса по отдельности, не учитывает регистр и диакритические знаки.

<Example id="autocomplete-search-smart" />

### Список рядом с курсором

`kbqAutocompleteRelativeToCaret` размещает раскрывающийся список рядом с текстовым курсором. В широких полях варианты дополнения появляются там, куда скорее всего направлен взгляд.

### Автодополнение в тексте

`kbqAutocompleteTextMode` вставляет выбранный вариант после курсора, не заменяя содержимое поля. Режим подходит для многострочных полей, слэш-команд и упоминаний.

<Example id="autocomplete-textarea" />

#### Символы-триггеры

`kbqAutocompleteTriggers` задает символы и строки, с которых начинается запрос. Например, `/` используют для команд, а `@` — для упоминаний.

<Example id="autocomplete-triggers" />

#### Подсказка в строке

Бледный текст после курсора показывает, как дополнится ввод. При выключенном `autoActiveFirstOption` подсказка появится после начала навигации по списку.

### Ширина раскрывающегося списка

По умолчанию ширина списка зависит от содержимого, но не бывает меньше поля и `panelMinWidth` (200 px). Атрибуты `panelWidth` и `panelMinWidth` изменяют ширину списка:

```html
<!-- По ширине поля, но не меньше panelMinWidth -->
<kbq-autocomplete panelWidth="auto" />

<!-- Точная ширина; panelMinWidth не применяется -->
<kbq-autocomplete [panelWidth]="400" />

<!-- Подходит любое CSS-значение, например сжатие по содержимому -->
<kbq-autocomplete panelWidth="fit-content" />

<!-- Увеличить нижнюю границу по умолчанию -->
<kbq-autocomplete [panelMinWidth]="350" />

<!-- Изменена максимальная ширина раскрывающегося списка -->
<kbq-autocomplete [panelMaxWidth]="800" />
```

Ширина списка увеличивается до 640 px. Ограничение не делает список меньше поля и не влияет на явно заданный `panelWidth`. Токен `--kbq-panel-size-width-max` задает ограничение глобально. Он общий для [Select](ru/components/select), [Tree-select](ru/components/tree-select) и [Dropdown](ru/components/dropdown).

### Управление с клавиатуры

| Клавиша    | Действие                                                                                                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ↓          | Открывает список.<br />Если список открыт, перемещает фокус на следующий доступный вариант                                                                                                           |
| ↑          | Перемещает фокус на предыдущий доступный вариант                                                                                                                                                     |
| →          | Принимает подсказку в строке, закрывает список и оставляет фокус в поле                                                                                                                              |
| Enter      | Если в списке выделен вариант, выбирает его, закрывает список и оставляет фокус в поле.<br />Если включен режим текста, вставляет выбранный вариант в позицию текстового курсора без перевода строки |
| Esc, Alt+↑ | Закрывает список и оставляет фокус в поле                                                                                                                                                            |
| Tab        | Закрывает список и переводит фокус на следующий элемент.<br />В режиме подсказки в строке подставляет ее, закрывает список и оставляет фокус в поле                                                  |
