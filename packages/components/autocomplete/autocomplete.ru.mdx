**Autocomplete** предлагает подходящие варианты в выпадающем списке по мере ввода и позволяет выбрать значение, не вводя его целиком.

### Поиск

Чтобы **Autocomplete** искал каждое слово запроса независимо от других, не учитывал регистр и диакритические знаки, добавьте `createSearchPredicate` в фильтрацию вариантов — это включит [умный поиск](/ru/other/search-smart).

<Example id="autocomplete-search-smart" />

### Список рядом с курсором

С атрибутом `kbqAutocompleteRelativeToCaret` выпадающий список открывается рядом с текстовым курсором. В широком поле пользователю не нужно переводить взгляд: варианты появляются там же, где он вводит текст.

### Автодополнение в тексте

С атрибутом `kbqAutocompleteTextMode` выбранная подсказка вставляется после курсора, а не заменяет все содержимое поля. Такой режим подходит для многострочных полей, слэш-команд и упоминаний.

<Example id="autocomplete-textarea" />

#### Символы-триггеры

`kbqAutocompleteTriggers` задает символы и строки, после которых появляется дополнение. Например, `/` можно использовать для команд, а `@` — для упоминаний.

<Example id="autocomplete-triggers" />

#### Подсказка в строке

Бледный текст после курсора показывает, как дополнится ввод. При выключенном `autoActiveFirstOption` подсказка появится после начала навигации по списку.

### Ширина выпадающего списка

По умолчанию список подстраивается под содержимое и не становится меньше ширины поля или `panelMinWidth` (по умолчанию 200 px). Это можно изменить атрибутами `panelWidth` и `panelMinWidth`:

```html
<!-- По ширине поля, но не меньше panelMinWidth -->
<kbq-autocomplete panelWidth="auto" />

<!-- Точная ширина; panelMinWidth не применяется -->
<kbq-autocomplete [panelWidth]="400" />

<!-- Подходит любое CSS-значение, например сжатие по содержимому -->
<kbq-autocomplete panelWidth="fit-content" />

<!-- Увеличить нижнюю границу по умолчанию -->
<kbq-autocomplete [panelMinWidth]="350" />

<!-- Изменена максимальная ширина раскрывающегося списка -->
<kbq-autocomplete [panelMaxWidth]="800" />
```

Рост по содержимому останавливается на 640 px. Ограничение мягкое: оно не делает панель меньше ширины поля и не уменьшает явно заданный `panelWidth`. Изменить его глобально можно токеном `--kbq-panel-size-width-max`, общим с [Select](ru/components/select), [Tree-select](ru/components/tree-select) и [Dropdown](ru/components/dropdown).

Эти же атрибуты работают, когда Autocomplete подключен к [полю с тегами](ru/components/tags): ширина списка считается по всему полю, а не по полю ввода внутри него.

### Управление с клавиатуры

| Клавиша       | Действие                                                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ↓             | Открывает список.<br />Если список открыт, перемещает фокус на следующий доступный вариант.                                                                                       |
| ↑             | Перемещает фокус на предыдущий доступный вариант                                                                                                                                  |
| →             | Принимает предложение в режиме подсказки в тексте, закрывает список и оставляет фокус в поле                                                                                      |
| Enter         | Если вариант активен, выбирает его, закрывает список и оставляет фокус в поле.<br />Если включён режим текста, вставляет выбранный вариант в позицию каретки без перевода строки. |
| Escape, Alt+↑ | Закрывает список и оставляет фокус в поле                                                                                                                                         |
| Tab           | Закрывает список и переводит фокус на следующий элемент.<br />В режиме подсказки в тексте подставляет её, закрывает список и оставляет фокус в поле.                              |
