#### Только для чтения

В режиме `readonly` значение поля нельзя изменить, но доступно выделение текста и копирование в буфер обмена, а поле попадает в фокус. Элементы, которые меняют значение, отключены: кнопка очистки скрыта, степпер числового поля неактивен. Иконки и кнопки, которые значение не меняют, остаются доступны.

#### Числовое поле

Это специальное поле для ввода только чисел. Система автоматически форматирует введенное значение, например добавляет разделители тысяч.

<Example id="input-number-overview" />

Когда разделителем тысяч является тонкий пробел, директива `kbqNormalizeWhitespace` заменяет его при вставке из буфера обмена. Это поведение не установлено по умолчанию — его можно включить вручную.

#### Маска ввода

Используйте библиотеку [Maskito](https://maskito.dev/), чтобы автоматически расставлять разделители и ограничивать ввод символов:

```bash
npm install @maskito/core @maskito/angular @maskito/kit
```

<Example id="input-with-mask" />

#### Автозаполнение

Для часто используемых полей можно включить браузерное автозаполнение. После фокуса браузер предложит ранее введенные значения, что сокращает время заполнения формы.

Если браузер по умолчанию автоматически заполняет поле, это можно отключить с помощью `autocomplete="off"`.

### Рекомендации

- Плейсхолдер не должен быть примером допустимого значения.
- Подсказки размещайте под полем ввода.
- Для многострочного текста предназначен компонент [Textarea](/ru/components/textarea).
- [Autocomplete](/ru/components/autocomplete) подойдет, когда система может предложить готовые значения, но при этом должна сохраняться возможность ввести другой текст.
- Используйте [Datepicker](/ru/components/datepicker) для выбора даты и [Timepicker](/ru/components/timepicker) для выбора времени.
