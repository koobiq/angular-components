#### Read-only

In `readonly` mode, the value cannot be changed, but the text can be selected and copied, and the field can receive focus. Controls that change the value are disabled: the cleaner is hidden and the number-field stepper is inactive. Icons and buttons that do not change the value remain available.

#### Search field

Use a regular field when search should remain visible. If space is limited and search is needed on demand, use [Search Expandable](/en/components/search-expandable) — the field expands from an icon button.

#### Number field

A dedicated field for entering numbers. It automatically formats the entered value, for example by adding thousands separators.

<Example id="input-number-overview" />

When the thousands separator is a thin space, the `kbqNormalizeWhitespace` directive replaces it when pasting from the clipboard. This behavior is not enabled by default and can be turned on manually.

#### Input mask

Use [Maskito](https://maskito.dev/) to insert separators automatically and restrict entered characters:

```bash
npm install @maskito/core @maskito/angular @maskito/kit
```

<Example id="input-with-mask" />

#### Autocomplete

Browser autocomplete can be enabled for frequently used fields. On focus, the browser suggests previously entered values, reducing the time needed to fill in the form.

If the browser makes a field autocomplete-enabled by default, disable this with `autocomplete="off"`.

### Recommendations

- Do not use the placeholder as an example of a valid value.
- Place hints below the input.
- Use [Textarea](/en/components/textarea) for multiline text.
- Use [Autocomplete](/en/components/autocomplete) when the system can suggest ready-made values while still allowing the user to enter different text.
- Use [Datepicker](/en/components/datepicker) to select a date and [Timepicker](/en/components/timepicker) to select a time.
