### Добавление файлов

По умолчанию каждый новый выбор файлов добавляется к уже загруженным — так удобно собирать список за несколько заходов.

Если нужно, чтобы новый выбор заменял предыдущий — как в обычном системном диалоге выбора файлов, — используйте `addStrategy="replace"`.

### Допустимые типы файлов

`accept` подставляется в атрибут `accept` нативного поля выбора файла и работает ровно как платформенный: он фильтрует то, что предлагает системный диалог, и не более того. Пользователь может переключить диалог на «Все файлы», а перетащенный файл с ним вообще не сверяется.

Чтобы отклонить файл, нужна валидация контрола. `FileValidators.isCorrectExtension` принимает тот же список, поэтому оба можно взять из одного поля, а отклоненный файл попадет в список с сообщением об ошибке — примеры валидации собраны на вкладке «Примеры».

О файлах, которые компонент отбросил сам, сообщает `(rejected)`: для одиночного загрузчика это все файлы после первого, для множественного со стратегией `concat` — дубликаты уже добавленных.

### Доступность и клавиатура

Порядок обхода: ссылка выбора файла, затем кнопки удаления выбранных файлов в порядке списка. `Delete` и `Backspace` удаляют файл, на кнопке которого стоит фокус; после удаления фокус переходит на занявшую его место кнопку, а если список опустел — на поле выбора файла.

Проецируемые сообщения `kbq-hint` связаны с полем выбора файла через `aria-describedby`, а само поле получает `aria-invalid`, пока контрол в состоянии ошибки. Добавление и удаление файлов объявляются в live-регионе самого компонента; формулировки берутся из активной локали и переопределяются через `KBQ_LOCALE_DATA`.
