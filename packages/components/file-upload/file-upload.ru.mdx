### Добавление файлов

По умолчанию каждый новый выбор файлов добавляется к уже загруженным — так удобно собирать список за несколько заходов.

Если нужно, чтобы новый выбор заменял предыдущий — как в обычном системном диалоге выбора файлов, — используйте `addStrategy="replace"`.

<Example id="file-upload-multiple-add-strategy" />

### Допустимые типы файлов

`accept` попадает в одноименный атрибут нативного поля выбора файла и работает как платформенный: фильтрует состав системного диалога. Пользователь может переключить диалог на «Все файлы», а перетащенный файл с `accept` не сверяется.

Чтобы отклонить файл, добавьте валидатор контрола. `FileValidators.isCorrectExtension` принимает тот же список расширений, поэтому задайте его один раз и передайте обоим. Отклоненный файл попадает в список с сообщением об ошибке — примеры валидации собраны на вкладке «Примеры».

О файлах, которые компонент отбросил, сообщает выход `(rejected)`: у одиночного загрузчика это файлы после первого, у множественного со стратегией `concat` — дубликаты уже добавленных.

### Доступность и клавиатура

`Tab` переводит фокус на ссылку выбора файла, затем на кнопки удаления в порядке файлов. `Delete` и `Backspace` удаляют файл, на кнопке которого стоит фокус. После удаления фокус переходит на кнопку, занявшую его место, а если список опустел — на поле выбора файла.

Добавление и удаление файлов компонент объявляет в собственном live-регионе формулировками активной локали; чтобы заменить их, используйте `[localeOverrides]` или `kbqFileUploadLocaleConfigurationProvider`.
