Сплиттер меняет размеры соседних панелей перетаскиванием разделителя между ними — чтобы пользователь мог расширить нужную колонку и сузить остальные.

Панели должны быть непосредственными детьми `kbq-splitter`: панель внутри обёртки в раскладку не попадёт.

<!-- example(splitter-overview) -->

## Оформление

Атрибут `appearance` задаёт вид разделителя:

| Вид           | Описание                                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------------------------- |
| `divider`     | Разделительная линия. Вариант используется по умолчанию                                                        |
| `transparent` | Разделителя не видно, о нём говорит только курсор. Подходит там, где у границы панели уже есть своё оформление |
| `handle`      | Ручка по центру границы                                                                                        |

`kbqSplitterOptionsProvider` задаёт оформление по умолчанию для всего приложения или отдельного инжектора.

<!-- example(splitter-appearance) -->

## Ориентация

Атрибут `orientation` задаёт направление, вдоль которого выкладываются панели: `horizontal` располагает их в строку, `vertical` — в столбец.

<!-- example(splitter-orientation) -->

## Отключение

Атрибут `disabled` запрещает менять размеры: разделители перестают реагировать на перетаскивание и клавиатуру, уходят из порядка обхода и показывают обычный курсор.

<!-- example(splitter-disabled) -->

## Размер и ограничения

Размер панели задают три атрибута:

| Атрибут   | Описание                                                                        |
| --------- | ------------------------------------------------------------------------------- |
| `size`    | Начальный размер. Панели без него делят между собой то, что не заняли остальные |
| `minSize` | Наименьший размер, до которого панель можно сжать                               |
| `maxSize` | Наибольший размер, до которого панель можно растянуть                           |

Значение задаётся числом пикселей (`240`) или долей сплиттера (`'30%'`); в одном сплиттере единицы можно смешивать.

Если соседняя панель упёрлась в своё ограничение, разделитель продолжает двигаться: недостающее место берётся у следующих за ней панелей, поэтому вместе с ним сдвигается и соседний разделитель.

<!-- example(splitter-constraints) -->

## Привязка к размеру

Атрибут `snapSizes` задаёт размеры, к которым притягивается панель. Во время перетаскивания разделитель идёт ровно за указателем, а притяжение срабатывает в момент отпускания.

Атрибут `snapTolerance` задаёт расстояние, с которого притягивает каждая точка: по умолчанию 32px, значение по умолчанию меняется через `kbqSplitterOptionsProvider`.

<!-- example(splitter-snap) -->

## Свёрнутая панель

Атрибут `collapsible` разрешает сворачивать панель перетаскиванием, `collapsedSize` задаёт ширину свёрнутой полоски. Промежуточных размеров у такой панели нет: при перетаскивании она останавливается на `minSize`, а если тянуть дальше — сворачивается.

`collapsedSize`, равный нулю, скрывает панель совсем. Разделителя, за который её можно вернуть, тогда не остаётся — предусмотрите кнопку или комбинацию клавиш и разверните панель через двустороннюю привязку `[(collapsed)]`.

## Управление с клавиатуры

Разделитель попадает в порядок обхода между содержимым соседних панелей и реализует паттерн [Window Splitter](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/). Рамка фокуса показывается только при управлении с клавиатуры — она не видна, когда пользователь тянет разделитель мышкой.

| <div style="min-width: 180px;">Клавиша</div>                                                               | Поведение                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| <span class="docs-hot-key-button">Left Arrow</span> \ <span class="docs-hot-key-button">Right Arrow</span> | Сдвигает вертикальный разделитель по направлению стрелки.                                                                                     |
| <span class="docs-hot-key-button">Up Arrow</span> \ <span class="docs-hot-key-button">Down Arrow</span>    | Сдвигает горизонтальный разделитель по направлению стрелки.                                                                                   |
| <span class="docs-hot-key-button">Home</span>                                                              | Устанавливает минимальный доступный размер панели. Если панель уже находится в минимальном размере и её можно сворачивать, она сворачивается. |
| <span class="docs-hot-key-button">End</span>                                                               | Устанавливает максимальный доступный размер панели. В том числе это может поджать соседние панели.                                            |
| <span class="docs-hot-key-button">Enter</span>                                                             | Сворачивает и разворачивает панель, если такая возможность включена флагом `collapsible`.                                                     |
| <span class="docs-hot-key-button">F6</span> \ <span class="docs-hot-key-button">Shift + F6</span>          | Навигация к следующей или предыдущей панели.                                                                                                  |
| <span class="docs-hot-key-button">Double Click</span>                                                      | Сбрасывает размеры до объявленных панелями. Повторный двойной клик устанавливает минимальный размер панели.                                   |
