Подключение шрифтов, чем отличаются источники и как переопределить стили типографики.

### Подключение шрифтов

Koobiq по умолчанию использует шрифты [Inter](https://github.com/rsms/inter) и [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).

| Шрифт          | Начертания                             |
| -------------- | -------------------------------------- |
| Inter          | 400, 500, 600, 700; курсив — 400 и 600 |
| JetBrains Mono | 400, 600, 700                          |

Шрифты подключают из npm-пакетов или вручную — файлами и ссылкой с CDN.

#### Пакеты

Оба шрифта ставятся из npm: Inter — [из пакета inter-ui](https://www.npmjs.com/package/inter-ui), JetBrains Mono — [из @fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

Из пакета **inter-ui** берут `inter.css`: файл полный — с кириллицей, привычными спецсимволами и перечеркнутым нулем. Сборку `inter-latin.css` не используют: в ней нет ни кириллицы, ни части фич.

```scss
@import 'inter-ui/inter.css';

@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

#### CDN и самохостинг

Google Fonts для Inter не подходит: он отдает шрифт обрезанным — без части привычных символов и без фич, объявленных в токенах Koobiq, — например, не отображается перечеркнутый 0. Inter берут файлами: [rsms.me/inter/download](https://rsms.me/inter/download/), в архиве готовый файл стилей.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono можно подключить по ссылке с Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

#### Текстовые стили

Готовый класс использует отдельные переменные дизайн-токенов: шрифт, кегль, интерлиньяж, трекинг, вес, регистр и OpenType-фичи. Все классы перечислены [в дизайн-токенах](/ru/main/design-tokens/typography).

В разработке преимущественно используются готовые классы, а не собственные стили из отдельных переменных: переменные дизайн-токенов нужны для частичной кастомизации. Классы есть в теме, а при сборке темы миксинами их добавляет SCSS-миксин `koobiq-typography()`.

```html
<h2 class="kbq-headline">Заголовок</h2>
<p class="kbq-text-normal">Текст интерфейса</p>
```

#### Как изменить шрифты

Семейства шрифтов заданы глобальными переменными, их переопределение меняет шрифты во всем интерфейсе:

```scss
/* после css-tokens: селектор тот же :root, решает порядок подключения */
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

#### Проверка файлов

Перед подключением шрифт проверяют: в файле из вашего источника должны быть символы, которые использует интерфейс, и OpenType-фичи, которые включает Koobiq. Раздача по `unicode-range` — так работают CDN и собранные из них сабсеты, например Inter в Fontsource — выбрасывает вместе с глифами и фичи.
