Типографика Koobiq определяет шрифты, начертания и текстовые стили для создания единообразной визуальной иерархии в интерфейсах.

### Подключение шрифтов

Koobiq по умолчанию использует шрифты [Inter](https://github.com/rsms/inter) и [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).

| Шрифт          | Начертания                             |
| -------------- | -------------------------------------- |
| Inter          | 400, 500, 600, 700; курсив — 400 и 600 |
| JetBrains Mono | 400, 600, 700                          |

Шрифты подключают из npm-пакетов или вручную — файлами и ссылкой с CDN. Пакеты предпочтительнее: они отдают полные файлы.

#### Пакеты

Оба шрифта ставятся из npm: Inter — из [inter-ui](https://www.npmjs.com/package/inter-ui), JetBrains Mono — из [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

```scss
// Inter: inter.css объявляет все нужные начертания и берёт полные файлы из папки web/
@import 'inter-ui/inter.css';

// JetBrains Mono
@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

В пакете inter-ui рядом с `inter.css` лежат `inter-latin.css` и папки `*-latin` — это урезанные сборки, в них нет ни кириллицы, ни части фич. Берите только `inter.css`.

#### CDN или свои файлы

Google Fonts для Inter не подходит: CDN отдаёт шрифт нарезанным по `unicode-range`, вместе с глифами из файла пропадают фичи — ноль из токенов Koobiq рисуется без черты, альтернативные цифры не появляются. Поэтому Inter берут файлами: [rsms.me/inter/download](https://rsms.me/inter/download/), в архиве готовый `inter.css`.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono можно подключить по ссылке с Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

#### Текстовые стили

Готовые текстовые стили лежат в токенах: семейство, кегль, интерлиньяж, трекинг, вес, регистр и OpenType-фичи собраны в переменные `--kbq-typography-<стиль>-*`. Используйте их классами, а не собирайте свой стиль из отдельных свойств — так текст совпадает с компонентами. Готовая тема `prebuilt-themes/theme.css` содержит классы сразу, при сборке темы их отдаёт `koobiq-typography()` из `@koobiq/components/core/styles/koobiq-theme`.

```html
<h2 class="kbq-headline">Заголовок</h2>
<p class="kbq-text-normal">Текст интерфейса</p>
```

#### Как изменить шрифты

Переопределите глобальные переменные семейств:

```scss
/* после подключения токенов */
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

#### Проверьте шрифт перед подключением

Перед подключением проверьте шрифт из вашего источника: в нём должны быть символы, которые использует интерфейс, и OpenType-фичи, которые включает Koobiq. Раздача по `unicode-range` — так работают CDN и собранные из них сабсеты, например Inter в Fontsource — выбрасывает вместе с глифами и фичи.
