Типографика Koobiq определяет шрифты, начертания и текстовые стили для создания единообразной визуальной иерархии в интерфейсах.

### Подключение шрифтов

Koobiq по умолчанию использует шрифты [Inter](https://github.com/rsms/inter) и [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).

| Шрифт          | Начертания                             |
| -------------- | -------------------------------------- |
| Inter          | 400, 500, 600, 700; курсив — 400 и 600 |
| JetBrains Mono | 400, 600, 700                          |

Шрифты подключают из npm-пакетов или вручную — файлами и ссылкой с CDN. Пакеты предпочтительнее: они отдают полные файлы.

#### Пакеты

Оба шрифта ставятся из npm: Inter — из [inter-ui](https://www.npmjs.com/package/inter-ui), JetBrains Mono — из [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

```scss
// Inter: inter.css объявляет все нужные начертания и берёт полные файлы из папки web/
@import 'inter-ui/inter.css';

// JetBrains Mono
@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

В пакете inter-ui рядом с `inter.css` лежат `inter-latin.css` и папки `*-latin` — это урезанные сборки, в них нет ни кириллицы, ни части фич. Берите только `inter.css`.

#### CDN или свои файлы

Google Fonts для Inter не подходит: CDN отдаёт шрифт нарезанным по `unicode-range`, вместе с глифами из файла пропадают фичи — ноль из токенов Koobiq рисуется без черты, альтернативные цифры не появляются. Поэтому Inter берут файлами: [rsms.me/inter/download](https://rsms.me/inter/download/), в архиве готовый `inter.css`.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono можно подключить по ссылке с Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

Или возьмите начертания из [релизов JetBrains](https://github.com/JetBrains/JetBrainsMono/releases) — они лежат в `fonts/webfonts` — и объявите их в глобальных стилях.

#### Текстовые стили

Текстовые стили живут в дизайн-токенах: `text-*`, `caps-*`, `display-*`, `italic-*`, `mono-*`, `tabular-*`, `title`, `headline` и `subheading` — 45 стилей. Каждый стиль — это набор переменных `--kbq-typography-<стиль>-*`: семейство, кегль, интерлиньяж, трекинг, вес, начертание, регистр и OpenType-фичи. Компоненты Koobiq берут значения только из этих переменных, поэтому правка токенов меняет вид всего интерфейса.

Те же стили доступны классами — их отдаёт `koobiq-typography()` из `@koobiq/components/core/styles/koobiq-theme`, а готовая тема `prebuilt-themes/theme.css` содержит их сразу — `.kbq-display-big`, `.kbq-headline`, `.kbq-title`, `.kbq-text-normal`, `.kbq-text-normal-strong`, `.kbq-caps-normal`, `.kbq-mono-normal`, `.kbq-tabular-normal` и остальные.

```html
<h2 class="kbq-headline">Заголовок</h2>
<p class="kbq-text-normal">Текст интерфейса</p>
<p class="kbq-text-compact">Подпись</p>
```

Отдельный уровень можно применить в своих стилях через `kbq-typography-level-to-styles-css-variables()` из `@koobiq/components/core/styles/common/tokens` — на нём и построены классы:

```scss
@use '@koobiq/components/core/styles/common/tokens' as tokens;

.my-caption {
    @include tokens.kbq-typography-level-to-styles-css-variables(typography, text-compact);
}
```

#### Как изменить шрифты

Все стили ссылаются на три переменные семейств: `--kbq-font-family-base` — текст, `--kbq-font-family-accent` — заголовки и дисплейные стили, `--kbq-font-family-mono` — моноширинный текст. Переопределите их, и интерфейс целиком перейдёт на ваши шрифты:

```scss
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

Объявляйте переопределение после подключения токенов — иначе победит значение из токенов.

Один стиль меняется своей переменной, например только основной текст:

```scss
:root {
    --kbq-typography-text-normal-font-family: 'MySans', sans-serif;
    --kbq-typography-text-normal-font-feature-settings: 'ss01', 'zero';
}
```

#### Проверьте шрифт перед подключением

Перед подключением проверьте шрифт из вашего источника: в нём должны быть символы, которые использует интерфейс, и OpenType-фичи, которые включает Koobiq. Раздача по `unicode-range` — так работают CDN и собранные из них сабсеты, например Inter в Fontsource — выбрасывает вместе с глифами и фичи.

#### Фичи из токенов

OpenType-фичи Koobiq включает через дизайн-токены — для текста приложения достаточно взять значения из них:

```scss
body {
    font-family: var(--kbq-typography-text-normal-font-family);
    font-feature-settings: var(--kbq-typography-text-normal-font-feature-settings);
}
```
