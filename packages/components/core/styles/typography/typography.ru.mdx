Типографика Koobiq определяет шрифты, начертания и текстовые стили для создания единообразной визуальной иерархии в интерфейсах.

### Добавление шрифтов

Koobiq по умолчанию использует шрифты [Inter](https://github.com/rsms/inter) и [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).

| Шрифт          | Жирность | Стиль   |
| -------------- | -------- | ------- |
| JetBrains Mono | 400      | Обычный |
| JetBrains Mono | 600      | Обычный |
| JetBrains Mono | 700      | Обычный |
| Inter          | 400      | Обычный |
| Inter          | 400      | Курсив  |
| Inter          | 500      | Обычный |
| Inter          | 500      | Курсив  |
| Inter          | 600      | Обычный |
| Inter          | 700      | Обычный |

#### Откуда брать шрифты

Берите официальные сборки: Inter — с [rsms.me/inter/download](https://rsms.me/inter/download/), JetBrains Mono — из [релизов JetBrains](https://github.com/JetBrains/JetBrainsMono/releases). Источник может быть и любым другим: важен сам шрифт, а не то, откуда вы его скачали. Если удобнее ставить шрифты из npm, подойдут [inter-ui](https://www.npmjs.com/package/inter-ui) или [dist-font-inter](https://www.npmjs.com/package/dist-font-inter) для Inter и [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono) для JetBrains Mono: стили моноширинного текста не включают ни одной фичи, поэтому сабсеты этого пакета ничего не теряют. Папки `*-latin` в inter-ui урезаны: в них нет ни кириллицы, ни части фич.

Скопируйте файлы в проект и объявите их в глобальных стилях. В архиве Inter уже есть готовый `inter.css` — он объявляет и статические начертания, и переменный шрифт:

```scss
@import 'assets/fonts/inter/inter.css';
```

Для JetBrains Mono нужны начертания 400, 600 и 700 — они лежат в папке `fonts/webfonts` архива JetBrains Mono:

```scss
@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 400;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-Regular.woff2') format('woff2');
}

@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 600;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-SemiBold.woff2') format('woff2');
}

@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 700;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-Bold.woff2') format('woff2');
}
```

#### Проверьте шрифт перед подключением

Часть источников отдаёт урезанный шрифт. CDN-раздача Google Fonts и собранные из неё пакеты (например, Fontsource) отдают шрифт нарезанным на сабсеты по `unicode-range`: вместе с глифами из файла пропадают OpenType-фичи. Шрифт при этом подключается, но часть фич и символов молча перестаёт работать: ноль из токенов Koobiq рисуется без черты, альтернативные цифры не появляются, а отдельные символы вроде `₽` или длинного тире подменяются системным шрифтом. Сам файл шрифта при этом может быть полным: например, семейство, скачанное с fonts.google.com, содержит все глифы и фичи — урезает его именно раздача по частям.

Поэтому перед подключением проверьте шрифт из вашего источника: в нём должны быть символы, которые использует интерфейс, и OpenType-фичи, которые включает Koobiq.

#### Фичи из токенов

OpenType-фичи Koobiq включает через дизайн-токены — для текста приложения достаточно взять значения из них:

```scss
body {
    font-family: var(--kbq-typography-text-normal-font-family);
    font-feature-settings: var(--kbq-typography-text-normal-font-feature-settings);
}
```
