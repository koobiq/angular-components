Koobiq typography defines the fonts, weights, and text styles used to create a consistent visual hierarchy in interfaces.

### Connecting Fonts

Koobiq uses the [Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) fonts by default.

| Font           | Weights                                  |
| -------------- | ---------------------------------------- |
| Inter          | 400, 500, 600, 700; italic — 400 and 600 |
| JetBrains Mono | 400, 600, 700                            |

Fonts come from npm packages or are wired up by hand — from files and a CDN link.

#### Packages

Both fonts are installed from npm: Inter from [inter-ui](https://www.npmjs.com/package/inter-ui), JetBrains Mono from [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

```scss
// Inter: inter.css declares every weight we need and takes the full files from the web/ folder
@import 'inter-ui/inter.css';

// JetBrains Mono
@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

In the inter-ui package `inter-latin.css` and the `*-latin` folders sit next to `inter.css` — those are trimmed builds, with neither Cyrillic nor some of the features. Only `inter.css` is suitable.

#### A CDN and self-hosting

Google Fonts does not work for Inter: it serves the font trimmed — without some of the usual symbols and without the features the Koobiq tokens declare, so, for example, the slashed zero does not appear. Inter comes as files: [rsms.me/inter/download](https://rsms.me/inter/download/), where the archive ships a ready `inter.css`.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono can be linked from Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

#### Text styles

The ready-made text styles live in the tokens: family, size, line height, letter spacing, weight, text transform and OpenType features are collected in the `--kbq-typography-<style>-*` variables. The styles are applied as classes rather than assembled from individual properties — that way the text matches the components. The prebuilt `prebuilt-themes/theme.css` ships the classes; when the theme is built by hand, `koobiq-typography()` of `@koobiq/components/core/styles/koobiq-theme` emits them.

```html
<h2 class="kbq-headline">Heading</h2>
<p class="kbq-text-normal">Interface text</p>
```

#### How to change the fonts

The fonts are changed by overriding the global family variables:

```scss
/* after the tokens are connected */
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

#### Checking the font before installing it

A font from any source is checked before installing: it has to contain the characters the interface uses and the OpenType features Koobiq enables. Serving by `unicode-range` — which is what CDNs and the subsets built from them do, Inter in Fontsource for example — drops the features along with the glyphs.
