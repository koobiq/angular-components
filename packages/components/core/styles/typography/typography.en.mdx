Connecting fonts, how the sources differ and how to override the typography styles.

### Connecting Fonts

Koobiq uses the [Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) fonts by default.

| Font           | Weights                                  |
| -------------- | ---------------------------------------- |
| Inter          | 400, 500, 600, 700; italic — 400 and 600 |
| JetBrains Mono | 400, 600, 700                            |

Fonts come from npm packages or are wired up by hand — from files and a CDN link.

#### Packages

Both fonts are installed from npm: Inter — [from the inter-ui package](https://www.npmjs.com/package/inter-ui), JetBrains Mono — [from the @fontsource/jetbrains-mono package](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

The **inter-ui** package ships `inter.css`, which has the full font feature set — Cyrillic, popular special symbols and the slashed zero. `inter-latin.css` is not used: it has neither Cyrillic nor some of the features.

```scss
@import 'inter-ui/inter.css';

@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

#### A CDN and self-hosting

Google Fonts does not work for Inter: it serves the font trimmed — without some of the popular symbols and without the features the Koobiq tokens declare, so, for example, the slashed zero does not appear. Inter comes [as files from rsms.me](https://rsms.me/inter/download/), where the archive ships a ready-made stylesheet.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono can be linked from Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

#### Text styles

A ready-made class uses the separate design token variables: font family, size, line height, letter spacing, weight, text transform and OpenType features. Every class is listed [in the design tokens](/en/main/design-tokens/typography).

The ready-made classes are used in development rather than custom styles assembled from individual variables: the design token variables are there for partial customization. The classes come [with the theme](/en/main/theming/overview), and when it is built from SCSS mixins, `koobiq-typography()` adds them.

```html
<h2 class="kbq-headline">Heading</h2>
<p class="kbq-text-normal">Interface text</p>
```

#### Changing the fonts

The font families are set by global variables, and overriding them changes the fonts across the interface. The override goes after the tokens are connected, otherwise the value from the tokens applies.

```scss
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

#### Checking the files

A font from any source is checked before installing: it has to contain the characters the interface uses and the OpenType features Koobiq enables. Serving by **unicode-range** — which is what CDNs and the subsets built from them do, Inter in Fontsource for example — drops the features along with the glyphs.
