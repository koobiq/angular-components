Koobiq typography defines the fonts, weights, and text styles used to create a consistent visual hierarchy in interfaces.

### Installing Fonts

Koobiq uses the [Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) fonts by default.

| Font           | Weight | Style  |
| -------------- | ------ | ------ |
| JetBrains Mono | 400    | Normal |
| JetBrains Mono | 600    | Normal |
| JetBrains Mono | 700    | Normal |
| Inter          | 400    | Normal |
| Inter          | 400    | Italic |
| Inter          | 500    | Normal |
| Inter          | 500    | Italic |
| Inter          | 600    | Normal |
| Inter          | 700    | Normal |

#### Where to get the fonts

Use the official builds: Inter from [rsms.me/inter/download](https://rsms.me/inter/download/), JetBrains Mono from the [JetBrains releases](https://github.com/JetBrains/JetBrainsMono/releases). Any other source works as well — the font itself is what matters, not where you downloaded it from. If you prefer installing the fonts from npm, [inter-ui](https://www.npmjs.com/package/inter-ui) or [dist-font-inter](https://www.npmjs.com/package/dist-font-inter) work for Inter, and [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono) for JetBrains Mono. The `*-latin` folders in inter-ui are trimmed: they contain neither Cyrillic nor some of the features.

Copy the files into your project and declare them in your global styles. The Inter archive already ships an `inter.css` that declares both the static weights and the variable font:

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono is needed in weights 400, 600, and 700 — they live in the `fonts/webfonts` folder of the JetBrains Mono archive:

```scss
@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 400;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-Regular.woff2') format('woff2');
}

@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 600;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-SemiBold.woff2') format('woff2');
}

@font-face {
    font-family: 'JetBrains Mono';
    font-style: normal;
    font-weight: 700;
    font-display: swap;
    src: url('assets/fonts/jetbrains-mono/JetBrainsMono-Bold.woff2') format('woff2');
}
```

#### Check the font before installing it

Some sources serve a trimmed font. The Google Fonts CDN and the packages built from it (Fontsource, for example) serve files split into subsets by `unicode-range`, and the OpenType features are dropped along with the glyphs. The font still loads, but some features and characters silently stop working: the zero from the Koobiq tokens loses its slash, the alternate digits never appear, and characters such as `₽` or the em dash fall back to a system font. The font file itself can still be complete: a family downloaded from fonts.google.com contains every glyph and feature — the trimming happens in the way the CDN serves it.

So before installing the font, check the one your source serves: it has to contain the characters your interface uses and the OpenType features Koobiq enables.

#### Features from the tokens

Koobiq enables the OpenType features through design tokens — for app text, take the values from the tokens:

```scss
body {
    font-family: var(--kbq-typography-text-normal-font-family);
    font-feature-settings: var(--kbq-typography-text-normal-font-feature-settings);
}
```
