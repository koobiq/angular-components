Koobiq typography defines the fonts, weights, and text styles used to create a consistent visual hierarchy in interfaces.

### Connecting Fonts

Koobiq uses the [Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) fonts by default.

| Font           | Weights                                  |
| -------------- | ---------------------------------------- |
| Inter          | 400, 500, 600, 700; italic — 400 and 600 |
| JetBrains Mono | 400, 600, 700                            |

Fonts come from npm packages or are wired up by hand — from files and a CDN link. The packages are preferable: they serve the full files.

#### Packages

Both fonts are installed from npm: Inter from [inter-ui](https://www.npmjs.com/package/inter-ui), JetBrains Mono from [@fontsource/jetbrains-mono](https://www.npmjs.com/package/@fontsource/jetbrains-mono).

```bash
npm install inter-ui @fontsource/jetbrains-mono
```

```scss
// Inter: inter.css declares every weight we need and takes the full files from the web/ folder
@import 'inter-ui/inter.css';

// JetBrains Mono
@import '@fontsource/jetbrains-mono/400.css';
@import '@fontsource/jetbrains-mono/600.css';
@import '@fontsource/jetbrains-mono/700.css';
```

In the inter-ui package `inter-latin.css` and the `*-latin` folders sit next to `inter.css` — those are trimmed builds, with neither Cyrillic nor some of the features. Take only `inter.css`.

#### A CDN or your own files

The Google Fonts CDN does not work for Inter: it serves the font split by `unicode-range`, and the features are dropped along with the glyphs — the zero from the Koobiq tokens loses its slash, the alternate digits never appear. So Inter comes as files: [rsms.me/inter/download](https://rsms.me/inter/download/), where the archive ships a ready `inter.css`.

```scss
@import 'assets/fonts/inter/inter.css';
```

JetBrains Mono can be linked from Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&display=swap" rel="stylesheet" />
```

Or take the weights from the [JetBrains releases](https://github.com/JetBrains/JetBrainsMono/releases) — they live in `fonts/webfonts` — and declare them in your global styles.

#### Text styles

The text styles live in the design tokens: `text-*`, `caps-*`, `display-*`, `italic-*`, `mono-*`, `tabular-*`, `title`, `headline` and `subheading` — 45 styles. Each style is a set of `--kbq-typography-<style>-*` variables: family, size, line height, letter spacing, weight, style, text transform and OpenType features. Koobiq components take their values only from these variables, so editing the tokens changes the whole interface.

The same styles are available as classes: `koobiq-typography()` of `@koobiq/components/core/styles/koobiq-theme` emits them, and the prebuilt `prebuilt-themes/theme.css` already ships them — `.kbq-display-big`, `.kbq-headline`, `.kbq-title`, `.kbq-text-normal`, `.kbq-text-normal-strong`, `.kbq-caps-normal`, `.kbq-mono-normal`, `.kbq-tabular-normal` and the rest.

```html
<h2 class="kbq-headline">Heading</h2>
<p class="kbq-text-normal">Interface text</p>
<p class="kbq-text-compact">Caption</p>
```

A single level can be applied in your own styles with the mixin from `@koobiq/components/core/styles/common/tokens` — the classes are built on it:

```scss
@use '@koobiq/components/core/styles/common/tokens' as tokens;

.my-caption {
    @include tokens.kbq-typography-level-to-styles-css-variables(typography, text-compact);
}
```

#### How to change the fonts

Every style points at three family variables: `--kbq-font-family-base` for text, `--kbq-font-family-accent` for headings and display styles, `--kbq-font-family-mono` for monospaced text. Override them and the whole interface switches to your fonts:

```scss
:root {
    --kbq-font-family-base: 'MySans', sans-serif;
    --kbq-font-family-accent: 'MyDisplay', 'MySans', sans-serif;
    --kbq-font-family-mono: 'MyMono', monospace;
}
```

Declare the override after the tokens are connected, otherwise the token value wins.

A single style is changed with its own variable — the main text, for example:

```scss
:root {
    --kbq-typography-text-normal-font-family: 'MySans', sans-serif;
    --kbq-typography-text-normal-font-feature-settings: 'ss01', 'zero';
}
```

#### Check the font before installing it

Before installing the font, check the one your source serves: it has to contain the characters your interface uses and the OpenType features Koobiq enables. Serving by `unicode-range` — which is what CDNs and the subsets built from them do, Inter in Fontsource for example — drops the features along with the glyphs.

#### Features from the tokens

Koobiq enables the OpenType features through design tokens — for app text, take the values from the tokens:

```scss
body {
    font-family: var(--kbq-typography-text-normal-font-family);
    font-feature-settings: var(--kbq-typography-text-normal-font-feature-settings);
}
```
