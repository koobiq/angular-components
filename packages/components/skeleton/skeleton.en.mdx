A skeleton is a temporary placeholder that previews the approximate shape of content while it loads. Use one when you know where the elements will appear.

### Basic block

The `<kbq-skeleton>` element is a basic rectangular block. Set its width and height with CSS. Combine several blocks into a custom composition when no preset fits.

<Example id="skeleton-basic" />

### Presets

Presets are ready-made placeholders for Koobiq components. Combine them to create a placeholder for an entire page.

#### Typography

`KbqSkeletonTypography` creates a placeholder with line heights that match the selected [Koobiq typography style](en/main/design-tokens/typography). When there are several lines, their widths alternate randomly. The uneven right edge makes the placeholder look more like a paragraph.

<Example id="skeleton-typography" />

#### Separate elements

Placeholders for [buttons](en/components/button), [badges](en/components/badge), [tags](en/components/tag), [icons](en/components/icon), and [links](en/components/link) match the height of their components. You can set their width with CSS.

<Example id="skeleton-elements" />

#### Element groups

`KbqSkeletonGroup` displays a row of placeholders of the same type: buttons, badges, tags, icons, or links.

<Example id="skeleton-group" />

#### Parameter block

The `KbqSkeletonDl` component displays a placeholder for a set of parameters and their values.

<Example id="skeleton-dl" />

#### Table

While a [table](en/components/table) or [AG Grid](en/components/ag-grid/overview) is loading, `KbqSkeletonTable` imitates its structure. You can set:

- the number of columns and the width of each column;
- the number of rows;
- whether to show checkboxes for selecting rows.

<Example id="skeleton-grid" />

#### Form field

`KbqSkeletonFormField` shows the label, field, and hint below it as one placeholder. The preset supports a multiline field and a label placed to its left.

<Example id="skeleton-form-field" />

#### Expandable section

`KbqSkeletonAccordion` displays a placeholder for the [accordion](en/components/accordion) component. The skeleton shows all groups collapsed.

<Example id="skeleton-accordion" />

#### Checkbox, radio button, and toggle

`KbqSkeletonCheckable` displays simplified placeholders for the label and a [checkbox](en/components/checkbox), [radio button](en/components/radio), or [toggle](en/components/toggle). You can also show a hint.

<Example id="skeleton-checkable" />

#### Tabs

`KbqSkeletonTabs` creates a placeholder for tabs. You can customize the tab content. By default, it shows lines of text.

<Example id="skeleton-tabs" />

#### Hierarchical list

`KbqSkeletonTree` displays a placeholder for a hierarchical list. The second node is expanded to show the nested structure.

<Example id="skeleton-tree" />

#### Global configuration

Use `kbqSkeletonPresetsConfigurationProvider` to configure presets for the entire application or individual pages.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### Guidelines

Use a skeleton when:

- The page or section structure is known in advance, and the data is loading for the first time.
- Loading takes a few seconds.

Do not use a skeleton in these cases:

- Loading takes less than 1 second; the skeleton can appear briefly and cause the interface to flicker.
- Use a [progress spinner](en/components/progress-spinner) when an action is in progress, such as saving, deleting, or submitting a form.
- For long-running tasks, such as file conversion or data transfer, use a [progress bar](en/components/progress-bar) or a [progress spinner](en/components/progress-spinner).
- You can keep the previous content on screen during an update. Show the update state separately.
- Another indicator already shows that content is loading.
