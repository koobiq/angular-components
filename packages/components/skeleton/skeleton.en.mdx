A skeleton is a temporary placeholder that reserves space for content while it loads and previews its structure. Use a skeleton when you know how the content is structured. It shows what to expect and helps prevent layout shifts.

### Basic block

The `<kbq-skeleton>` element displays a rectangular placeholder. Use styles to set its size. Choose the basic block when no preset fits your content or when you need to build a custom placeholder from simple blocks.

<Example id="skeleton-basic" />

### Presets

Presets are ready-made placeholders for common elements and components. Use a preset in place of a component that hasn't rendered yet, or combine several presets to show the structure of a loading block. Preset inputs let you set the number of items and adjust some layout details.

#### Elements

Separate presets are available for a [button](en/components/button), [badge](en/components/badge), [tag](en/components/tag), [icon](en/components/icon), and [link](en/components/link). Each placeholder matches the typical size of its component. For example, the badge placeholder is 56 × 24 pixels. To make it wider, set its width with styles.

<Example id="skeleton-elements" />

#### Typography

The preset matches the line height of the selected [Koobiq typography style](en/main/typography/overview). Set the style with `level` and the number of lines with `lines`. By default, the preset shows one line.

<Example id="skeleton-typography" />

#### Description list

The [description list](en/components/dl) preset shows pairs of placeholder terms and values. Use `rows` to set the number of pairs.

<Example id="skeleton-dl" />

#### Table

By default, the [table](en/components/table) preset shows a header row, three data rows, and three columns. Use `rows` to set the number of rows. Use `columns` to set the number of columns or each column's width. Set `header` to hide the header row, or set `selectable` to add a selection column with checkbox placeholders.

For [AG Grid](en/components/ag-grid/overview), the preset also supports pinned columns. Use `pinnedColumns` to set their number.

<Example id="skeleton-grid" />

#### Element groups

The `kbq-skeleton-group` preset displays a row of identical placeholders. Use it for a [tag list](en/components/tag-list) or a row of [badges](en/components/badge), for example. Set `preset` to choose the placeholder type and `count` to set the number of items. You can also use buttons, icons, and links.

<Example id="skeleton-group" />

#### Form field

The [form field](en/components/form-field) preset shows placeholders for the label, control, and hint. Set `control` to `input` or `textarea`. Use `label` and `hint` to show or hide each one. Set `horizontal` to place the label beside the control.

<Example id="skeleton-form-field" />

#### Accordion

The [accordion](en/components/accordion) preset shows placeholders for the titles and icons of collapsed items. Use `rows` to set the number of items.

<Example id="skeleton-accordion" />

#### Checkbox, radio button and toggle

The [checkbox](en/components/checkbox), [radio button](en/components/radio), or [toggle](en/components/toggle) preset shows placeholders for the control and its label. Set the control type with `control` and the number of controls with `rows`. Use `label` and `hint` to show or hide each one.

<Example id="skeleton-checkable" />

#### Tabs

The [tabs](en/components/tabs) preset shows placeholders for tabs and their content. Use `count` to set the number of tabs. Set `vertical` for a vertical layout and `contentLines` to set the number of content lines. You can also place other presets in the tab content instead of text lines.

<Example id="skeleton-tabs" />

#### Tree

The [tree](en/components/tree) preset shows placeholders for nodes and their labels. Use `rows` to set the number of top-level nodes and `children` to set the number of child nodes under the expanded item.

<Example id="skeleton-tree" />

#### Global configuration

Use `kbqSkeletonPresetsConfigurationProvider` to set default values for skeleton presets across your application or any part of it. Any value you omit comes from the nearest parent provider. If no parent provider is configured, Koobiq uses the default.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### The `kbqSkeleton` directive

The `kbqSkeleton` directive turns an existing element and its content into a placeholder while preserving the element's shape and size. Use it when content is loading or refreshing but the element is already in the markup. You don't need to load the data first: the directive uses the existing element to determine the placeholder's shape and size. For example, enable it on text, a badge, or a button while the associated content loads. You can't interact with the element while the directive is enabled.

If you can't render the element yet, use the basic block or a suitable preset. These options create placeholders without an existing element.

### Guidelines

Match the skeleton to the content structure so that loaded content appears in the same places.

Use a skeleton when:

- You need to preview the page structure while content loads and reduce layout shifts.
- The page takes 2 to 10 seconds to load.

Avoid skeletons when:

- Loading takes less than 1 second; no loading indicator is needed.
- Only one element is loading, such as a video. Use a [progress spinner](en/components/progress-spinner) instead.
- A long-running task is in progress, such as file conversion, uploading files, or downloading files. Use a [progress bar](en/components/progress-bar) or [progress spinner](en/components/progress-spinner) to show activity or progress.
