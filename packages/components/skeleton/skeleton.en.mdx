A skeleton is a temporary placeholder that previews the approximate shape of content while it loads. Use one when you know where the elements will appear.

### Basic block

The `<kbq-skeleton>` element is a simple rectangular placeholder. Set its width and height with CSS. Combine several blocks to create a custom placeholder when no preset fits.

<Example id="skeleton-basic" />

### Presets

Presets are ready-made placeholders for Koobiq components. Combine them to create a placeholder for an entire page.

#### Typography

`KbqSkeletonTypography` creates a placeholder with line heights that match the selected [Koobiq typography style](en/main/typography/overview). When there are several lines, their widths alternate in a set pattern. The uneven right edge makes the placeholder look like a paragraph.

<Example id="skeleton-typography" />

#### Separate elements

Placeholders for [buttons](en/components/button), [badges](en/components/badge), [tags](en/components/tag), [icons](en/components/icon), and [links](en/components/link) match the height of their components. You can set their width with styles.

<Example id="skeleton-elements" />

#### Element groups

`KbqSkeletonGroup` displays a row of the same placeholders: buttons, badges, tags, icons, or links.

<Example id="skeleton-group" />

#### Parameter block

`KbqSkeletonDl` displays placeholders for a set of parameters and their values.

<Example id="skeleton-dl" />

#### Table

While a [table](en/components/table) or [AG Grid](en/components/ag-grid/overview) is loading, `KbqSkeletonTable` imitates its structure. You can set:

- the number of columns and the width of each column;
- the number of rows;
- whether to show checkboxes for selecting rows.

<Example id="skeleton-grid" />

#### Form field

`KbqSkeletonFormField` shows the label, field, and hint below it as one placeholder. The preset supports a multiline field and a label placed to its left.

<Example id="skeleton-form-field" />

#### Expandable section

`KbqSkeletonAccordion` displays a placeholder for the [accordion](en/components/accordion) component. Its items are shown collapsed.

<Example id="skeleton-accordion" />

#### Checkbox, radio button, and toggle

`KbqSkeletonCheckable` displays simplified placeholders for the label and a [checkbox](en/components/checkbox), [radio button](en/components/radio), or [toggle](en/components/toggle). You can also show a hint.

<Example id="skeleton-checkable" />

#### Tabs

`KbqSkeletonTabs` creates a placeholder for tabs. You can customize the tab content; by default, it contains lines of text.

<Example id="skeleton-tabs" />

#### Hierarchical list

`KbqSkeletonTree` displays a placeholder for a hierarchical list. The second node is expanded to show the nested structure.

<Example id="skeleton-tree" />

#### Global configuration

Use the `kbqSkeletonPresetsConfigurationProvider` provider to configure presets for the entire application or parts of it.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### Guidelines

Use a skeleton when:

- The page or section structure is known in advance, and the data is loading for the first time.
- Loading takes a few seconds.

Do not use a skeleton in these cases:

- Loading takes less than 1 second; the skeleton can appear briefly and cause the interface to flicker.
- You need to show a user action in progress, such as saving, deleting, or submitting a form. Use a [progress spinner](en/components/progress-spinner) instead.
- A long-running task is in progress, such as file conversion or data transfer. Use a [progress bar](en/components/progress-bar) or a [progress spinner](en/components/progress-spinner).
- You can keep the previous content on screen during an update. Show the update state separately.
- Another indicator already shows that content is loading.
