Скелетон — временная заглушка, которая показывает примерную форму содержимого при загрузке. Подходит, если заранее известно расположение элементов.

### Базовый блок

`<kbq-skeleton>` — базовый элемент, простой прямоугольный блок. Ширина и высота настраиваются с помощью CSS-стилей. Несколько блоков можно объединить в собственную композицию, если нет подходящего шаблона.

<Example id="skeleton-basic" />

### Шаблоны

Шаблоны — готовые заглушки для компонентов Koobiq. Их можно сочетать, чтобы создать заглушку целой страницы.

#### Текст

`KbqSkeletonTypography` формирует заглушку с высотой строк, соответствующей выбранному [стилю типографики Koobiq](https://koobiq.io/ru/main/design-tokens/typography). Если строк несколько, их ширина чередуется случайным образом — неровный правый край создает большее сходство с абзацем текста.

<Example id="skeleton-typography" />

#### Отдельные элементы

Заглушки для [кнопки](ru/components/button), [бейджа](ru/components/badge), [тега](ru/components/tag), [иконки](ru/components/icon) и [ссылки](ru/components/link) повторяют высоту компонентов, а ширину можно настроить.

#### Группы элементов

`KbqSkeletonGroup` показывает ряд однотипных заглушек: кнопок, бейджей, тегов, иконок или ссылок.

<Example id="skeleton-group" />

#### Блок параметров

Компонент `KbqSkeletonDl` показывает заглушку для набора параметров и их значений.

<Example id="skeleton-dl" />

#### Таблица

Во время загрузки [таблицы](ru/components/table) или [AG grid](ru/components/ag-grid/overview) компонент `KbqSkeletonTable` имитирует структуру таблицы. Можно настроить:

- количество столбцов и ширину каждого столбца;
- количество строк;
- отображение флажков для выбора строк.

<Example id="skeleton-grid" />

#### Поле

Компонент `KbqSkeletonFormField` работает как единая заглушка для подписи, поля и подсказки под полем. Шаблон поддерживает многострочное поле и расположение подписи слева.

<Example id="skeleton-form-field" />

#### Раскрывающийся блок

Шаблон `KbqSkeletonAccordion` отображает заглушку компонента [Accordion](ru/components/accordion). Группы представлены в свернутом виде.

<Example id="skeleton-accordion" />

#### Флажок, выбор варианта и переключатель

Шаблон `KbqSkeletonCheckable` показывает в упрощенном виде подпись и компонент [Checkbox](ru/components/checkbox), [Radio button](ru/components/radio) или [Toggle](ru/components/toggle). Дополнительно можно отобразить подсказку.

#### Вкладки

`KbqSkeletonTabs` создает заглушку для вкладок. Содержимое вкладки можно настраивать. По умолчанию оно представлено в виде текста.

<Example id="skeleton-tabs" />

#### Иерархический список

`KbqSkeletonTree` показывает заглушку для иерархического списка. Второй узел раскрыт для отображения вложенности.

<Example id="skeleton-tree" />

#### Глобальная конфигурация

Провайдер `kbqSkeletonPresetsConfigurationProvider` настраивает шаблоны для всего приложения или отдельных страниц.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### Рекомендации

Скелетон подходит, если:

- структура страницы или ее раздела известна заранее, а данные загружаются впервые;
- загрузка занимает несколько секунд.

Скелетон не подходит:

- для быстрой загрузки (менее 1 секунды). В таком случае скелетон вызовет мерцание интерфейса;
- для реакции на действия пользователя. Например, для сохранения, удаления или отправки формы подходит [круговой индикатор](ru/components/progress-spinner);
- для длительных процессов. Например, для конвертации файлов или передачи данных подходит [полоса загрузки](ru/components/progress-bar) или [круговой индикатор](ru/components/progress-spinner);
- если при обновлении возможно оставить прежнее содержимое на экране. Состояние обновления отображают отдельно;
- если загрузка уже обозначена другим индикатором.
