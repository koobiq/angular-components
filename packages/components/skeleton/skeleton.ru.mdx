Скелетон — временная заглушка, которая показывается, пока настоящий контент загружается. Скелетон делает ожидание менее заметным и понятным. Пользователь видит структуру страницы и понимает, что интерфейс работает, а контент скоро появится.

### Базовый блок

`<kbq-skeleton>` — базовый элемент для создания заглушек из простых прямоугольных блоков. Ширина и высота каждого блока задаются стилями. Несколько таких элементов можно объединить в собственную композицию, если нет подходящего шаблона.

<Example id="skeleton-basic" />

### Шаблоны

Шаблоны — готовые заглушки для компонентов Кубика. Несколько шаблонов можно сочетать, чтобы показать структуру загружаемого содержимого.

#### Текст

`KbqSkeletonTypography` формирует текстовую заглушку с высотой строк, соответствующей выбранному [стилю типографики Koobiq](ru/main/typography/overview). Если строк несколько, их ширина чередуется, создавая неровный правый край.

Ряд одинаковых заглушек выбранного типа — кнопок, бейджей, тегов, иконок или ссылок — формирует `KbqSkeletonGroup`.

#### Список параметров

Компонент `KbqSkeletonDl` отображает пары «ключ — значение» [для списка параметров](ru/components/dl).

<Example id="skeleton-dl" />

#### Таблица

Во время загрузки [таблицы](ru/components/table) или [AG Grid](ru/components/ag-grid/overview) компонент `KbqSkeletonTable` имитирует структуру таблицы. В заглушке можно настроить:

- количество строк;
- количество столбцов и ширину каждого столбца;
- наличие строки заголовка;
- флажки для выбора строк;
- граница между закрепленными и остальными столбцами.

### Скелетон для отрисованного элемента

Директива [kbqSkeleton] работает с готовой разметкой: она накладывает заглушку на существующий блок, не удаляя его из DOM. Поэтому исходные размеры сохраняются.

### Рекомендации

Используйте скелетон:

- при первоначальной загрузке страницы или раздела;
- когда расположение контента известно заранее, а его структура предсказуема, например, в каталогах товаров, лентах новостей, списках пользователей и таблицах.

Скелетон не подходит в следующих случаях:

- Страница загружается менее чем за 1 секунду, поэтому кратковременное появление скелетона вызывает ненужное мерцание интерфейса.
- Для обозначения выполнения действий пользователя — сохранения, удаления или отправки формы — подходит [спиннер](ru/components/progress-spinner).
- Для длительных операций с измеримым прогрессом, например загрузки файлов, импорта данных или обработки документов, подходит [прогресс-бар](ru/components/progress-bar).
- При обновлении уже отображаемого контента данные можно оставить на экране и обозначить состояние обновления.
- Если состояние загрузки уже обозначено другим индикатором, скелетон не нужен.
