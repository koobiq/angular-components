`KbqSkeleton` - это временная заглушка, которая занимает место подгружаемого элемента и отображает его примерный макет, пока реальный контент еще загружается.

Директива `kbqSkeleton` ставится на готовый компонент или текст: пока идёт загрузка, заглушка повторяет его форму и размер.

#### Глобальная конфигурация

Сколько строк и элементов показывают пресеты без атрибутов, задаёт провайдер для всего приложения или его части. Ниже - значения по умолчанию. Ключи, которые провайдер не задаёт, берутся у ближайшего провайдера выше.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### Рекомендации

Заглушка должна повторять структуру страницы с реальным контентом, чтобы после загрузки содержимое появилось на тех же местах.

Используйте:

- Когда ожидаем возврата и отображения содержимого страницы для пользователя, чтобы обеспечить ощущение структуры страницы и минимизировать смещения макета.
- Если загрузка страницы занимает от 2 до 10 секунд, используйте скелетоны.

Не используйте:

- Если загрузка составляет менее 1 секунды, то никакие индикаторы загрузки не нужны.
- Если нужно отобразить загрузку отдельного элемента, например видео, то здесь нужен [круговой индикатор](ru/components/progress-spinner). Скелетоны лучше оставить для полностраничной загрузки.
- В случае длительных процессов, таких как конвертация файлов, загрузка/выгрузка данных, выбирайте [полосы загрузки](ru/components/progress-bar) или [круговые индикаторы](ru/components/progress-spinner), которые показывают оставшееся время или процент выполнения.
