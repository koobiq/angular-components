Скелетон — временная заглушка, которая занимает место загружаемого элемента и показывает его примерную форму.

Директива `kbqSkeleton` превращает уже созданный элемент разметки в заглушку: скрывает его содержимое и сохраняет его форму и размер.

<Example id="skeleton-overview" />

### Пресеты

Пресеты — готовые заглушки типовых компонентов с размерами по умолчанию. Чтобы после загрузки компонента соседние элементы не смещались, при необходимости переопределите размеры пресета стилями с учетом макета.

Например, размер заглушки бейджа по умолчанию — 56 × 24 пикселя. Если по макету бейдж должен быть шире, задайте заглушке нужную ширину стилями.

#### Глобальная конфигурация

Настройки провайдера задают, сколько строк и элементов показывают пресеты по умолчанию в приложении или его части. Если ключ не указан, используется его значение из ближайшего родительского провайдера.

```ts
import { kbqSkeletonPresetsConfigurationProvider } from '@koobiq/components/skeleton';

@Component({
    providers: [
        kbqSkeletonPresetsConfigurationProvider({
            typographyLines: 1,
            dlRows: 3,
            tableRows: 3,
            tableColumns: 3,
            groupCount: 3,
            accordionRows: 3,
            checkableRows: 1,
            tabsCount: 3,
            tabsContentLines: 3,
            treeRows: 3,
            treeChildren: 3
        })
    ]
})
```

### Рекомендации

Скелетон заранее показывает структуру загружаемого содержимого и помогает сохранить его место в макете.

Используйте скелетон:

- для загрузки, которая длится несколько секунд;
- для отдельной части страницы, если важно заранее обозначить место и форму содержимого.

Не используйте скелетон:

- если содержимое появляется почти сразу: индикатор обычно не нужен;
- если нужно показать только факт загрузки отдельного элемента, например видео: используйте [круговой индикатор](ru/components/progress-spinner). Скелетон подойдет, если важно заранее обозначить место и форму содержимого;
- для длительных процессов, например конвертации файлов или передачи данных: используйте [полосу загрузки](ru/components/progress-bar) или [круговой индикатор](ru/components/progress-spinner). Если известен ход процесса, покажите процент выполнения; иначе используйте неопределенный режим.
