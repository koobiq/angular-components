Скелетон — временная заглушка, которая показывает примерную форму загружаемого содержимого. Он подходит, если заранее известны его элементы и их расположение.

### Базовый блок

`<kbq-skeleton>` — базовый элемент для создания заглушек из простых прямоугольных блоков. Ширину и высоту каждого блока задают стилями. Несколько блоков можно объединить в собственную композицию, если нет подходящего шаблона.

<Example id="skeleton-basic" />

### Шаблоны

Шаблоны — готовые заглушки для компонентов Koobiq. Их можно сочетать, чтобы собрать заглушку страницы с разными компонентами.

#### Текст

`KbqSkeletonTypography` формирует текстовую заглушку с высотой строк, соответствующей выбранному [стилю типографики Koobiq](ru/main/typography/overview). Если строк несколько, их ширина чередуется, создавая неровный правый край.

<Example id="skeleton-typography" />

#### Элементы

Для [кнопки](ru/components/button), [бейджа](ru/components/badge), [тега](ru/components/tag), [иконки](ru/components/icon) и [ссылки](ru/components/link) есть специальные заглушки. Они повторяют высоту компонентов, ширину можно изменить стилями.

<Example id="skeleton-elements" />

#### Группы элементов

`KbqSkeletonGroup` показывает ряд одинаковых заглушек: кнопок, бейджей, тегов, иконок или ссылок.

<Example id="skeleton-group" />

#### Список параметров

Компонент `KbqSkeletonDl` отображает пары «ключ — значение» [для списка параметров](ru/components/dl).

<Example id="skeleton-dl" />

#### Таблица

Во время загрузки [таблицы](ru/components/table) или [AG Grid](ru/components/ag-grid/overview) компонент `KbqSkeletonTable` имитирует структуру таблицы. В заглушке можно настроить:

- количество строк;
- количество столбцов и ширину каждого столбца;
- наличие строки заголовка;
- флажки для выбора строк;
- количество закрепленных столбцов.

<Example id="skeleton-grid" />

#### Поле формы

Подпись, поле и подсказку [поля формы](ru/components/form-field) объединяет в упрощенной заглушке компонент `KbqSkeletonFormField`. Шаблон поддерживает многострочное поле и расположение подписи сбоку.

<Example id="skeleton-form-field" />

#### Аккордеон

Свернутые элементы [аккордеона](ru/components/accordion) представлены в `KbqSkeletonAccordion` заглушками заголовков и значков.

<Example id="skeleton-accordion" />

#### Чекбокс, радиокнопка и переключатель

Количество заглушек для [флажка](ru/components/checkbox), [радиокнопки](ru/components/radio) или [переключателя](ru/components/toggle) задает `KbqSkeletonCheckable`; также в группе можно отобразить подпись и подсказку.

<Example id="skeleton-checkable" />

#### Вкладки

`KbqSkeletonTabs` имитирует горизонтальное или вертикальное расположение [вкладок](ru/components/tabs). По умолчанию область вкладки заполнена строками текста, вместо которых можно вложить другие шаблоны.

<Example id="skeleton-tabs" />

#### Иерархический список

`KbqSkeletonTree` показывает узлы [иерархического списка](ru/components/tree); второй узел раскрыт.

<Example id="skeleton-tree" />

#### Глобальная конфигурация

Провайдер `kbqSkeletonPresetsConfigurationProvider` задает значения шаблонов для приложения или его части. Если он не задает значение, используется значение ближайшего родительского провайдера.

### Скелетон для отрисованного элемента

Директива `kbqSkeleton` подходит, когда разметка элемента уже есть, а данные еще загружаются. Она превращает элемент вместе с содержимым в единую заглушку по его внешнему контуру. При включенной директиве содержимое не отображается, а элемент исключен из порядка табуляции и дерева доступности.

### Рекомендации

Скелетон подходит, если:

- структура страницы или ее раздела известна заранее, а данные загружаются впервые;
- загрузка занимает несколько секунд.

Скелетон не подходит:

- если страница загружается менее чем за 1 секунду, скелетон может появиться на короткое время и вызвать мерцание интерфейса;
- для обозначения выполнения действия пользователя, например сохранения, удаления или отправки формы, подходит [круговой индикатор](ru/components/progress-spinner);
- для длительных процессов, например конвертации файлов или передачи данных, подходит [полоса загрузки](ru/components/progress-bar) или [круговой индикатор](ru/components/progress-spinner). Если ход процесса известен, можно показать процент выполнения; в противном случае используют неопределенный режим;
- если при обновлении можно оставить прежнее содержимое на экране, состояние обновления отображают отдельно;
- если загрузка уже обозначена другим индикатором, скелетон не нужен.
