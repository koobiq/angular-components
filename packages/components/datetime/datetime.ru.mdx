KbqDatetime — это компонент для ввода даты и времени в одном поле, данные которого хранятся в одном значении.

<Example id="datetime-overview" />

### Секунды

Формат времени с секундами задается свойством `format`.

<Example id="datetime-with-seconds" />

### Валидация

Свойства `min` и `max` ограничивают значение вместе с временем и закрывают дни в календаре за границами.

<Example id="datetime-validation" />

### Работа с клавиатурой

После ввода последней цифры даты фокус сам переходит в часы.

| <div style="min-width: 170px;">Клавиша</div>                                              | Действие                                                       |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| <span class="docs-hot-key-button">↓</span> <span class="docs-hot-key-button">↑</span>     | Уменьшить или увеличить выделенную часть даты или времени на 1 |
| <span class="docs-hot-key-button">→</span>                                                | Перейти к следующей части, из последней части даты — в часы    |
| <span class="docs-hot-key-button">←</span>                                                | Перейти к предыдущей части, из часов — в последнюю часть даты  |
| <span class="docs-hot-key-button">Backspace</span>                                        | Удалить символ, в пустом поле времени — перейти в дату         |
| <span class="docs-hot-key-button">Alt</span> + <span class="docs-hot-key-button">↓</span> | Открыть календарь из поля даты                                 |
| <span class="docs-hot-key-button">Esc</span>                                              | Закрыть календарь                                              |
