## Загрузка опций

Если опции не загружены, открывает панель с задержкой 100 мс. За этот короткий миг чаще всего список успеет загрузиться, а для пользователя это не ощущается, как тормоза интерфейса. Если данные не успели загрузиться, показываем меню с индикатором загрузки минимум на 300 мс, чтобы не было неприятного мелькания.

## Нет вариантов выбора

## Кастомная стратегия прокрутки

Стратегию прокрутки можно переопределить через токен `KBQ_SELECT_SCROLL_STRATEGY`. `KbqAutoHideScrollStrategy` (из `@koobiq/components/core`) останавливает изменение позиции, как только триггер выходит за пределы видимости, и генерирует событие в `hide` — подпишитесь на него, чтобы закрыть панель самостоятельно.

## Свой заголовок группы

Проецируйте контент в заголовок группы через атрибут `kbq-optgroup-label`: помеченный им элемент заменяет инпут `label`, и рядом с названием можно показать счётчик, иконки и любой другой контент. Импортируйте `KbqOptgroupLabel` (или целиком `KbqOptionModule`), иначе атрибут не подействует. Количество выбранных опций в группе даёт `selectedCount` самой группы, доступ к нему — по ссылке на шаблон (`exportAs` — `kbqOptgroup`).

Группа допускает не больше одного `kbq-optgroup-label`; лишние дают предупреждение в dev-режиме. `selectedCount` считает опции, отрисованные в группе, — при активном поиске он следует за отфильтрованным списком, как и строка «Выбрать все». Считаются только `KbqOption`: `kbq-list-option` внутри группы не учитывается. Оберните текст названия в `.kbq-truncate-line`, чтобы длинный заголовок обрезался, а не распирал узкую панель.
