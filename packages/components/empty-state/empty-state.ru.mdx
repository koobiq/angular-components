### Align

Содержимое может быть выровнено по центру или по верхнему краю. Выравнивание по верхнему краю включается атрибутом `alignTop`.

<Example id="empty-state-align" />

У компонента нет собственной высоты: как flex-элемент он растягивается, в остальных случаях занимает высоту содержимого. Тогда оба выравнивания выглядят одинаково. Чтобы выравнивание действовало, задайте высоту компоненту или его контейнеру — в примерах для этого используется `min-height`.

### Error

Компонент Empty State можно использовать для показа сообщения об ошибке. Атрибут `errorColor` окрашивает заголовок и текст в красный, вместе с ними — иконку в слоте иллюстрации.

#### Слоты под условием

У каждого слота свой селектор `ng-content`, слота для остального содержимого у компонента нет. Поэтому слот под условием должен быть корневым элементом блока `@if`:

```html
@if (failed()) {
<i kbq-empty-state-icon kbq-icon-item="kbq-triangle-exclamation_16"></i>
}
```

Если вложить один блок в другой — например, `@if (hasIcon())` с единственным вложенным `@if (wrapped()) … @else …`, — в корне окажется блок, а не элемент. Селектор не совпадет ни с чем, и Angular не спроецирует иллюстрацию: она пропадет из DOM без ошибки и предупреждения. Класс `kbq-empty-state_has-icon` при этом останется на хосте, потому что Angular создает директиву независимо от проекции.

Напишите для каждого варианта отдельный `@if` на одном уровне: `@if (hasIcon() && wrapped())` и `@if (hasIcon() && !wrapped())`.

### Accessibility

Компонент задает заголовку типографику `subheading` для обычного размера и `headline` для большого. Размечайте заголовок тем уровнем, который нужен странице: `<h2 kbq-empty-state-title>`, а не `div`. Собственный отступ браузера компонент обнуляет, поэтому верстка не меняется.

Заглушка появляется на уже прочитанной странице: после поиска без результатов или после неудавшегося запроса. Добавьте на `<kbq-empty-state>` атрибут `role="status"`, чтобы вспомогательные технологии сообщили о ней, или `role="alert"` для состояния ошибки — о нем они сообщают настойчивее.

Компонент не проставляет `role` сам: заглушке, которая была на странице с самого начала (например, изначально пустой список), сообщать не о чем.
