### Align

Содержимое может быть выровнено по центру или по верхнему краю. Выравнивание по верхнему краю включается атрибутом `alignTop`.

<Example id="empty-state-align" />

Собственной высоты у компонента нет: он растягивается как flex-элемент, а в любом другом контейнере занимает ровно высоту своего содержимого — и тогда оба выравнивания выглядят одинаково. Чтобы выравнивание что-то меняло, задайте высоту компоненту или его контейнеру: в примерах для этого используется `min-height`.

### Error

Компонент Empty State можно использовать для показа сообщения об ошибке. Это состояние включается атрибутом `errorColor`: заголовок и текст становятся красными, вместе с ними подкрашивается и иконка в слоте иллюстрации.

### Accessibility

Заголовок отрисовывается типографикой заголовка — `subheading` для обычного размера и `headline` для большого, — поэтому размечайте его настоящим заголовком того уровня, который нужен окружающей странице: `<h2 kbq-empty-state-title>`, а не `div`. Собственный отступ браузера у заголовка компонент обнуляет, так что от выбора элемента верстка не меняется.

Заглушка обычно появляется на уже прочитанной странице: после поиска, который ничего не нашел, или после неудавшегося запроса. Добавьте на `<kbq-empty-state>` атрибут `role="status"`, чтобы вспомогательные технологии сообщили о ней, либо `role="alert"` для состояния ошибки — о нем сообщают настойчивее.

Своего `role` компонент не проставляет: заглушке, которая была на странице с самого начала (например, изначально пустой список), сообщать не о чем.
