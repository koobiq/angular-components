`KbqLink` is a link that takes the user to another page, a document, or an external site.

<Example id="link-overview" />

### Size

The `size` attribute changes the font size and the gap to the icon.

<Example id="link-size" />

### Pseudo link

A pseudo link looks like a link, but acts as a button: it performs an action without leaving the page. Use it for an action inside text.

<Example id="link-pseudo" />

### Underline

The text underline is set with the `underline` attribute. A link is always underlined, and a pseudo link only on hover.

<Example id="link-underline" />

### Disabled state

The `disabled` attribute makes the link inactive. It keeps its address in the code, but cannot be followed.

<Example id="link-disabled" />

### Visited link

The `useVisited` attribute colors visited links. It is useful in a news feed or in articles.

<Example id="link-visited" />

### Icon

Set the icon before the text with `kbqLinkPrefix` and the icon after the text with `kbqLinkSuffix`. The icon is within the click area, but is not underlined.

<Example id="link-icons" />

### Multi-line link

If the link text is long, it wraps onto several lines.

<Example id="link-multi-line" />

### Prepositions and punctuation

The preposition that belongs to the link goes inside it. Punctuation after the link is included in it with the `kbqLinkSuffix` attribute: the text takes the link color, but is not underlined.

<Example id="link-in-text" />

### New tab and external pages

The `external` attribute adds the icon to a link to an external page or to a link that opens in a new tab. It does not open the page in a separate tab itself — add the `target="_blank"` attribute for that.

<Example id="link-external" />

### Third-party application

When the link opens another application, the link text must contain its name. Instead of the icon, the application logo can be used.

<Example id="link-application" />

### Print version

The `print` attribute adds the link address after its text when the page is printed, without the protocol and `www.`.

<Example id="link-print" />

### Default settings

`kbqLinkOptionsProvider` sets the default link settings for the whole application or for a single component.

```ts
bootstrapApplication(AppComponent, {
    providers: [kbqLinkOptionsProvider({ size: 'compact', useVisited: true })]
});
```

### Recommendations

- Open links in the same tab by default.
- A link should not lead to the page it is on — you click, the page loads, and you are where you started. The exception is a page with refreshable content, where the link duplicates the refresh.
- A user must be able to copy the address and open it in a new tab.
