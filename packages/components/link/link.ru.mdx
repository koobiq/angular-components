`KbqLink` — компонент, который связывает веб-страницы или выступает как более легкий аналог кнопки.

<Example id="link-overview" />

### Размер

Атрибут `size` отвечает за размер ссылки — типографику и отступы до иконок.

<Example id="link-size" />

### Подчеркивание

Атрибут `underline` отвечает за то, когда подчеркивается текст ссылки. По умолчанию ссылка подчеркнута всегда, а псевдоссылка — только при наведении.

<Example id="link-underline" />

### Неактивная ссылка

Атрибут `disabled` делает ссылку неактивной. Она сохраняет адрес, но перейти по ней нельзя.

<Example id="link-disabled" />

### Посещенная ссылка

Атрибут `useVisited` выделяет цветом посещенные ссылки. Это полезно на страницах-сборниках — в подборках статей и списках для чтения, где цвет отмечает прогресс чтения.

<Example id="link-visited" />

### Псевдоссылка

Псевдоссылка выглядит как ссылка, а действует как кнопка — выполняет действие, не уводя со страницы. Используйте ее для действия внутри текста.

<Example id="link-pseudo" />

### Содержимое

#### Иконка

Иконку перед текстом отметьте `kbqLinkPrefix`, иконку после текста — `kbqLinkSuffix`. Иконка входит в область клика, но не подчеркивается.

<Example id="link-icons" />

#### Многострочная ссылка

Длинная ссылка переносится на новую строку как обычный текст, и подчеркивается каждая строка.

<Example id="link-multi-line" />

#### Ссылка в тексте

Предлог, который относится к ссылке, включайте в нее. Точку в конце предложения поместите в элемент с `kbqLinkSuffix` — она окрашивается цветом ссылки, но не подчеркивается.

<Example id="link-in-text" />

### Страница перехода

#### Новая вкладка и внешние страницы

Атрибут `external` добавляет иконку ссылке на внешнюю страницу или ссылке, которая открывается в новой вкладке. Саму вкладку в отдельном окне он не открывает — для этого добавьте еще атрибут `target="_blank"`.

<Example id="link-external" />

#### Внешнее приложение

Если ссылка открывает другое приложение, назовите приложение в тексте ссылки. Вместо иконки можно показать логотип приложения через `kbqLinkSuffix`.

<Example id="link-application" />

### Печать

Атрибут `print` добавляет адрес ссылки после ее текста при печати страницы, без протокола и `www.`. Чтобы напечатать другой текст, передайте его в атрибут.

<Example id="link-print" />

### Настройки по умолчанию

`kbqLinkOptionsProvider` задает настройки ссылок по умолчанию для всего приложения или отдельного компонента. Значение, заданное у самой ссылки, имеет более высокий приоритет.

```ts
bootstrapApplication(AppComponent, {
    providers: [kbqLinkOptionsProvider({ size: 'compact', useVisited: true })]
});
```

### Рекомендации

- По умолчанию открывайте ссылки в той же вкладке.
- Для действия внутри текста используйте псевдоссылку. Для интерактивности вне текста — [кнопку без фона](/ru/components/button), у нее больше область нажатия.
- Для основного действия в [модальном диалоге](/ru/components/modal) используйте [кнопку](/ru/components/button).
- Ссылка не должна вести на ту же страницу, на которой находится — кликнул, страница загрузилась, и ты остался там же, где и был. Исключение — страница с обновляемым контентом, где ссылка дублирует обновление.
- Ссылка должна не только выглядеть, но и работать как ссылка. Используйте тег `<a>`, чтобы адрес можно было скопировать, а страницу — открыть в новой вкладке через контекстное меню.
- Текст ссылки отвечает на вопрос «что? куда?». Псевдоссылка формулируется как кнопка.
