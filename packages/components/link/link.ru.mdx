`KbqLink` — ссылка, которая ведет пользователя к другой странице, документу или внешнему сайту.

<Example id="link-overview" />

### Размер

Атрибут `size` меняет размер шрифта и отступ до иконки.

<Example id="link-size" />

### Псевдоссылка

Псевдоссылка выглядит как ссылка, а действует как кнопка — выполняет действие, не уводя со страницы. Используйте ее для действия внутри текста.

<Example id="link-pseudo" />

### Подчеркивание

Подчеркивание текста настраивается с помощью атрибута `underline`. Ссылка подчеркивается всегда, а псевдоссылка — только при наведении.

<Example id="link-underline" />

### Неактивное состояние

Атрибут `disabled` делает ссылку неактивной. Она сохраняет адрес в коде, но перейти по ней нельзя.

<Example id="link-disabled" />

### Посещенная ссылка

Атрибут `useVisited` выделяет цветом посещенные ссылки. Это полезно в ленте новостей или в статьях.

<Example id="link-visited" />

### Иконка

Иконка перед текстом задается атрибутом `kbqLinkPrefix`, а после текста — `kbqLinkSuffix`. Иконка входит в область клика, но не подчеркивается.

<Example id="link-icons" />

### Многострочная ссылка

Если текст ссылки длинный, можно настроить перенос на несколько строк.

<Example id="link-multi-line" />

### Предлоги и знаки препинания

Предлог, который относится к ссылке, должен входить в нее. Знак препинания после ссылки включается в нее с помощью атрибута `kbqLinkSuffix` — текст окрашивается, но не подчеркивается.

<Example id="link-in-text" />

### Новая вкладка и внешние страницы

Атрибут `external` добавляет иконку ссылке на внешнюю страницу или ссылке, которая открывается в новой вкладке. Саму вкладку в отдельном окне он не открывает — для этого необходим атрибут `target="_blank"`.

<Example id="link-external" />

### Стороннее приложение

Если открывается другое приложение, в тексте ссылки должно быть его название. Вместо иконки можно использовать логотип приложения.

### Версия для печати

Атрибут `print` добавляет адрес ссылки после ее текста при печати страницы, без протокола и `www.`.

<Example id="link-print" />

### Настройки по умолчанию

`kbqLinkOptionsProvider` задает настройки ссылок по умолчанию для всего приложения или отдельного компонента.

```ts
bootstrapApplication(AppComponent, {
    providers: [kbqLinkOptionsProvider({ size: 'compact', useVisited: true })]
});
```

### Рекомендации

- По умолчанию открывайте ссылки в той же вкладке.
- Ссылка не должна вести на ту же страницу, на которой находится — кликнул, страница загрузилась, и ты остался там же, где и был. Исключение — страница с обновляемым контентом, где ссылка дублирует обновление.
- Должна быть возможность скопировать адрес и открыть в новой вкладке.
