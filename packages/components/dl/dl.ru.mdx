Description list отображает пары терминов и описаний в адаптивном, горизонтальном или вертикальном формате.

<Example id="dl-overview" />

### Широкий формат

Атрибут `wide` делит ширину между терминами и описаниями поровну.

<Example id="dl-wide" />

### Вертикальный формат

Атрибут `vertical` отвечает за вертикальный формат, в котором термины располагаются над описаниями.

<Example id="dl-vertical" />

### Адаптивный формат

Без атрибута `vertical` список становится вертикальным, когда его ширина не больше `verticalBreakpoint`. Измените ширину контейнера, чтобы это увидеть.

<Example id="dl-vertical-breakpoint" />

### Выравнивание

Атрибут `verticalAlign` выравнивает термины и описания внутри строки, а `horizontalAlign` внутри колонки. Оба атрибута принимают значения `start`, `center` и `end`.

<Example id="dl-alignment" />

### Ширина термина

Атрибут `dtWidth` задает ширину колонки терминов в пикселях.

<Example id="dl-dt-width" />

### Изменение ширины колонок

Атрибут `resizable` позволяет менять ширину колонки терминов перетаскиванием разделителя или клавишами со стрелками. Двойной щелчок по разделителю сворачивает колонку до минимальной ширины, а повторный возвращает ее. Атрибут `resizerAriaLabel` задает доступное имя разделителя.

<Example id="dl-resizable" />

#### Минимальная ширина

Атрибуты `dtMinWidth` и `ddMinWidth` задают минимальную ширину колонок терминов и описаний в пикселях.

<Example id="dl-min-width" />

#### Общая ширина

Двусторонняя привязка `[(dtWidth)]` хранит ширину, заданную пользователем, чтобы ее можно было сохранить или синхронизировать между списками.

<Example id="dl-width-sync" />

### Длинный текст

Длинные строки без пробелов, например идентификаторы, хеш-суммы, пути и URL, переносятся в пределах своей колонки.

<Example id="dl-long-text" />

### Глобальные настройки

Функция `kbqDlOptionsProvider` задает параметры по умолчанию для всех списков приложения или конкретного инжектора.

```ts
import { ApplicationConfig } from '@angular/core';
import { kbqDlOptionsProvider } from '@koobiq/components/dl';

export const appConfig: ApplicationConfig = {
    providers: [kbqDlOptionsProvider({ wide: true, resizable: true })]
};
```
