## Количество видимых пунктов

`max` ограничивает число одновременно показанных пунктов: остальные сворачиваются в выпадающий список за кнопкой раскрытия. Кнопка занимает одно из мест, поэтому `[max]="4"` отображает три пункта и кнопку. Значение `null` снимает ограничение, и тогда пункты скрываются при нехватке ширины.

`routerLink` рекомендуется указывать у каждого `kbq-breadcrumb-item`: выпадающий список строит скрытые пункты из `text` и `routerLink`, поэтому пункт без адреса превращается в строку без перехода.

## Отключенное состояние

`disabled` переводит хлебные крошки в режим только для чтения: пункты и кнопка раскрытия перестают вести на страницы и не принимают фокус по клавише <span class="docs-hot-key-button">Tab</span>.

```ts
@Component({
    template: `
        <nav
            kbq-breadcrumbs
            [disabled]="isReadOnly"
            >...
        </nav>
    `
})
```

У отдельного пункта есть собственный `disabled` с тем же действием.

### Отрицательный отступ

По умолчанию панель хлебных крошек смещена влево на `--kbq-breadcrumb-item-negative-margin`, используя негативный отступ. Это поведение можно изменить при помощи свойства `firstItemNegativeMargin`.

Для определенных хлебных крошек:

```ts
@Component({
    template: `
        <nav
            kbq-breadcrumbs
            [firstItemNegativeMargin]="false"
            >...
        </nav>
    `
})
```

Для всех хлебных крошек в модуле, используя _Dependency Injection_ при помощи `kbqBreadcrumbsConfigurationProvider` провайдера:

```ts
import { kbqBreadcrumbsConfigurationProvider } from '@koobiq/components/breadcrumbs';

@NgModule({
    providers: [
        kbqBreadcrumbsConfigurationProvider({
            firstItemNegativeMargin: false
        })
    ]
})
```

## Доступность

Хлебные крошки — это ориентир навигации. Компонент проставляет роль `navigation` на `<kbq-breadcrumbs>`, а у `<nav kbq-breadcrumbs>` эта роль есть изначально.

Доступное имя приходит из активной локали. Если на странице несколько блоков хлебных крошек, им нужно задать разные имена через `aria-label` — так вспомогательные технологии их различат:

```html
<nav kbq-breadcrumbs aria-label="Навигация по разделу">...</nav>
```

Разделитель по умолчанию скрыт от вспомогательных технологий, поэтому они не зачитывают знаки между пунктами. Разделитель, переданный через `kbqBreadcrumbsSeparator`, тоже нужно скрыть:

```html
<ng-template kbqBreadcrumbsSeparator>
    <span aria-hidden="true">→</span>
</ng-template>
```

Последнему пункту компонент проставляет атрибут `aria-current="page"`. Если хлебные крошки не заканчиваются текущей страницей — например, карточка открыта из списка, — нужный пункт отмечают свойством `current`.
