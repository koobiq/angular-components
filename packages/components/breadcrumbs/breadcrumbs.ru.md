## Количество видимых пунктов

`max` ограничивает число одновременно показанных пунктов, остальные сворачиваются в выпадающий список за кнопкой раскрытия. Кнопка занимает одно из мест, поэтому `[max]="4"` отображает три пункта и кнопку. Значение `null` снимает ограничение, и пункты скрываются только по нехватке ширины.

Указывайте `routerLink` у каждого `kbq-breadcrumb-item`: выпадающий список строит скрытые пункты из `text` и `routerLink`, поэтому пункт без адреса превращается в строку, которая никуда не ведет.

## Отключенное состояние

`disabled` переводит всю цепочку в режим только для чтения: пункты и кнопка раскрытия перестают вести на страницы и выходят из последовательности перехода по <span class="docs-hot-key-button">Tab</span>.

```ts
@Component({
    template: `
        <nav
            kbq-breadcrumbs
            [disabled]="isReadOnly"
            >...
        </nav>
    `
})
```

У отдельного пункта есть собственный `disabled`, который делает то же самое для одного пункта.

### Отрицательный отступ

По умолчанию панель хлебных крошек смещена влево на `--kbq-breadcrumb-item-negative-margin`, используя негативный отступ. Это поведение можно изменить при помощи свойства `firstItemNegativeMargin`.

Для определенных хлебных крошек:

```ts
@Component({
    template: `
        <nav
            kbq-breadcrumbs
            [firstItemNegativeMargin]="false"
            >...
        </nav>
    `
})
```

Для всех хлебных крошек в модуле, используя _Dependency Injection_ при помощи `kbqBreadcrumbsConfigurationProvider` провайдера:

```ts
import { kbqBreadcrumbsConfigurationProvider } from '@koobiq/components/breadcrumbs';

@NgModule({
    providers: [
        kbqBreadcrumbsConfigurationProvider({
            firstItemNegativeMargin: false
        })
    ]
})
```

## Доступность

Цепочка — это ориентир навигации. На `<kbq-breadcrumbs>` роль `navigation` проставляется автоматически, а `<nav kbq-breadcrumbs>` несет ее сам.

Доступное имя берется из активной локали. Если на странице несколько цепочек, задайте им разные имена через `aria-label`, чтобы вспомогательные технологии их различали:

```html
<nav kbq-breadcrumbs aria-label="Навигация по разделу">...</nav>
```

Разделитель по умолчанию скрыт от вспомогательных технологий, поэтому знаки между пунктами не зачитываются. Разделитель, переданный через `kbqBreadcrumbsSeparator`, должен делать то же самое:

```html
<ng-template kbqBreadcrumbsSeparator>
    <span aria-hidden="true">→</span>
</ng-template>
```

Последний пункт цепочки помечается атрибутом `aria-current="page"`. Если цепочка не заканчивается текущей страницей — например, карточка открыта из списка, — пометьте нужный пункт свойством `current`.
