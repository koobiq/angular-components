AG grid предназначен для работы с большими таблицами. Компонент поддерживает сортировку, виртуальную прокрутку, изменение ширины и порядка колонок. Основан на библиотеке [ag-grid-angular](https://www.ag-grid.com/angular-data-grid/).

### Стилизация таблиц

Для единства стиля таблиц в проектах создана тема [`@koobiq/ag-grid-angular-theme`](https://github.com/koobiq/data-grid/blob/main/packages/ag-grid-angular-theme/README.md). Она включает готовые стили, соответствующие дизайн-системе. Тема поддерживает основные функции AG grid и упрощает настройку внешнего вида таблицы.

#### Установка

Установите следующие пакеты:

```bash
npm install @koobiq/ag-grid-angular-theme@^34 ag-grid-community@^34 ag-grid-angular@^34
```

#### Подключение темы

Импортируйте тему в основной файл стилей `styles.scss`:

```scss
@use '@koobiq/ag-grid-angular-theme';
```

Примените тему для `<ag-grid-angular>` в шаблоне:

```ts
import { KbqAgGridThemeModule } from '@koobiq/ag-grid-angular-theme';
import { AgGridModule } from 'ag-grid-angular';

@Component({
    imports: [AgGridModule, KbqAgGridThemeModule],
    template: `<ag-grid-angular kbqAgGridTheme />`
})
```

Полная документация по использованию темы хранится [в репозитории на GitHub](https://github.com/koobiq/data-grid/blob/main/packages/ag-grid-angular-theme/README.md).

### Отключение стилей фокуса ячеек

Для этого добавьте атрибут `kbqAgGridThemeDisableCellFocusStyles` к `<ag-grid-angular>`:

```html
<ag-grid-angular kbqAgGridTheme kbqAgGridThemeDisableCellFocusStyles />
```

### Меню колонок

Директива `kbqAgGridColumnMenu` добавляет в правый верхний угол таблицы кнопку, которая открывает меню управления колонками. В меню можно показывать и скрывать колонки, менять их порядок перетаскиванием, закреплять слева или справа и находить колонку по названию. Кнопка сброса возвращает колонки к исходному состоянию.

Ограничения задаются через `ColDef`:

- `lockVisible: true` запрещает скрывать колонку. Последнюю видимую колонку скрыть нельзя в любом случае.
- `lockPinned: true` запрещает закреплять и откреплять колонку.

По умолчанию используются русские подписи. Для смены языка подключите провайдер:

```ts
providers: [kbqAgGridColumnMenuLabelsProvider(KBQ_AG_GRID_COLUMN_MENU_LABELS_EN)];
```

### Скелетон в ячейках

`KbqAgGridSkeletonCellRenderer` рисует скелетон в ячейке строки, ещё не загруженной моделью бесконечной прокрутки (`rowModelType="infinite"`). Подставьте его через `cellRendererSelector` в `defaultColDef`: строка считается незагруженной, когда `data` равно `undefined`, а `undefined` в ответе оставляет остальные строки той ячейке, которую колонка рисует обычно:

```ts
readonly defaultColDef: ColDef = {
    cellRendererSelector: ({ data }: ICellRendererParams) =>
        data === undefined ? { component: KbqAgGridSkeletonCellRenderer } : undefined
};
```

Каждая полоска занимает всю ширину своей колонки: строки приходят под уже видимые колонки, с которыми им и надо совпадать, а полоски разной длины только создавали бы ощущение шатающейся таблицы. Другой случай — холодный старт выше: там заглушка подменяет собой грид целиком, и её полоски как раз разной длины.

Точно так же подставьте `KbqAgGridSkeletonSelectionCellComponent` в `selectionColumnDef`, чтобы колонка с чекбоксом не выбивалась и не показывала интерактивный чекбокс у строки без данных. Тема намеренно останавливается на самих компонентах и оставляет эту связку вам: директива подмешивала бы себя в описание колонки уже после инициализации таблицы, а AG Grid переписывает эту опцию целиком на каждую новую ссылку из инпута.

Количество строк-скелетонов задают две опции AG Grid, обе по умолчанию равны одной строке: `infiniteInitialRowCount` до первой загрузки и `cacheOverflowSize` во время загрузки следующей порции. Таблица считывает их, когда собирает кэш блоков, и дальше держится за снятые значения, поэтому новое подействует только тогда, когда кэш будет собран заново, — а собрать его заново заставляет новый источник данных. Пример с ошибкой загрузки ниже переключает одну строку на три именно так.

Заодно не обманывайте таблицу насчёт размера набора: отвечайте `-1`, пока данные ещё не кончились, — в том числе для страниц, которые вы отдаёте из собственного кэша. Источник данных, назвавший итог раньше времени, обрывает сценарий прокрутки: таблица разложит все строки сразу и перестанет добавлять хвостовые, на которых и рисуются скелетоны.

### Ошибки загрузки

Если порция данных не загрузилась, `kbqAgGridLoadError` заменяет её строкой-ошибкой во всю ширину со ссылкой для повтора. Строка прокручивается по вертикали вместе с данными, остаётся на месте при горизонтальной прокрутке, перекрывает закреплённые колонки и подхватывает высоту строки и разделители, заданные в таблице.

Штатный `failCallback()` у AG Grid навсегда оставляет строки упавшего блока пустыми и не порождает события на уровне таблицы, поэтому источник данных должен сообщить об ошибке директиве сам, передав `startRow` упавшего запроса:

```ts
error: () => {
    params.failCallback();
    this.loadError().fail(params.startRow);
};
```

Повтор вызывает `refreshInfiniteCache()`, который помечает на перезагрузку все блоки кэша — поблочного повтора в Community-редакции нет. Храните уже полученные страницы в источнике данных и отдавайте их оттуда, чтобы в сеть уходила только упавшая страница.

По умолчанию используются русские подписи. Чтобы сменить язык, передайте провайдер подписей:

```ts
providers: [kbqAgGridLoadErrorLabelsProvider(KBQ_AG_GRID_LOAD_ERROR_LABELS_EN)];
```

Если язык может смениться, пока таблица уже на экране, привязывайте набор подписей к инпуту `kbqAgGridLoadErrorLabels`, а не передавайте через провайдер: инпут сигнальный, поэтому уже отрисованная строка-ошибка подхватит новые подписи. Пример ниже вычисляет их от `KbqLocaleService` — русские для `ru-RU`, английские для остальных локалей.

Если грид не использует скелетоны, покажите на том же месте текстовый индикатор загрузки — как переключатель в примере ниже. Эта строка принадлежит приложению, поэтому и локализуется в нём — от той же локали, что и подписи строки-ошибки. Такой индикатор занимает одну строку, и его подпись начинается там, где был бы чекбокс выделения, поэтому рисуйте его через `isFullWidthRow` и `fullWidthCellRenderer`: у строки во всю ширину нет ячеек, так что подпись ничем не сдвинута и чекбокс рядом с ней не рисуется. Сдвинуть на колонку выделения подпись, которая лежит внутри ячейки, не получится — ячейка обрезает всё, что выходит за её границы.

### Выбор строк при бесконечной прокрутке

При бесконечной прокрутке данные подгружаются блоками, поэтому выбрать их все обычным списком нельзя — большая часть еще не загружена. Директива `kbqAgGridInfiniteSelection` инвертирует выбор: вместо перечня выбранных строк она хранит признак «выбраны все» и список исключений.

Такое состояние повторяет условие «все, кроме указанных ID», поэтому его можно передать на сервер, не загружая все строки.

Директиве нужны два параметра:

- `kbqAgGridInfiniteSelectionDatasource` принимает источник данных. Когда выбраны все строки, подгружаемые блоки добавляются в выбор автоматически.
- `getRowId` возвращает стабильный уникальный идентификатор строки.
