В этом руководстве описана настройка Angular-проекта для использования `@koobiq/components`.

### Установка зависимостей

Установка с помощью [Angular CLI](https://angular.dev/cli/add) — рекомендуемый способ, так как
Angular-пакеты будут установлены той версии, на которой уже находится приложение:

```bash
ng add @koobiq/components
```

`ng add` также добавляет стили в `angular.json`, классы темы в `index.html` и провайдер темы в приложение.
`--theme` выбирает `light`, `dark` или `auto` — по умолчанию, тема следует цветовой схеме системы. Локаль и шрифты
настраиваются отдельно, как описано ниже.

Ручная установка. Сначала установите `@angular/cdk` той версии, которая уже стоит в `package.json`
для `@angular/core`:

```bash
npm install @angular/cdk@^21.2.0
```

Затем установите библиотеку и остальные её зависимости:

```bash
npm install @koobiq/components overlayscrollbars@2.7.3 @koobiq/icons @koobiq/design-tokens@^4 @koobiq/angular-luxon-adapter @koobiq/luxon-date-adapter @koobiq/date-adapter @koobiq/date-formatter luxon
```

Версия `overlayscrollbars` зафиксирована, а не задана кареткой: скроллбар рассчитан на этот
конкретный релиз, и ту же версию устанавливает `ng add`. `@koobiq/design-tokens` ограничен 4-й мажорной
версией: под неё собрана эта версия библиотеки.

`@koobiq/angular-luxon-adapter` (или `@koobiq/angular-moment-adapter`) нужен только при использовании
компонентов для работы с датами — [datepicker](/ru/components/datepicker),
[timepicker](/ru/components/timepicker) или [filter-bar](/ru/components/filter-bar). Каждый из них —
обёртка над базовым адаптером, который нужно установить рядом: `@koobiq/luxon-date-adapter` или
`@koobiq/moment-date-adapter`. npm добавляет базовый пакет сам, Yarn и pnpm — нет, поэтому указывайте
его явно. Адаптер подключается рядом с локалью, см. ниже. Установите `marked`, если используете [markdown](/ru/components/markdown), `highlight.js`,
если используете [code-block](/ru/components/code-block), и `@angular/router`, если используете
[breadcrumbs](/ru/components/breadcrumbs).

### Обнаружение изменений

Компонентам не нужен zone.js. Они работают в приложении без zone.js, как принято по умолчанию с
Angular 21, и продолжают работать в приложении, которое загружает zone.js и предоставляет
`provideZoneChangeDetection()`. Настраивать для них ничего не нужно. Чтобы перевести существующее
приложение на работу без zone.js, уберите `provideZoneChangeDetection()` из его провайдеров
(`ng update` до Angular 21 добавляет его в запуск, где нет провайдера обнаружения изменений) и
`zone.js` из его `polyfills`. `provideZonelessChangeDetection()` лишь явно задает поведение по
умолчанию: рядом с `provideZoneChangeDetection()` он выводит предупреждение NG0408, а какой из них
применится, решает порядок провайдеров.

```typescript
import { provideZonelessChangeDetection } from '@angular/core';

bootstrapApplication(AppComponent, {
    // Без provideZoneChangeDetection(); этот провайдер необязателен.
    providers: [provideZonelessChangeDetection()]
});
```

### Анимации

Анимации компонентов работают на CSS и не требуют настройки: не нужны ни `@angular/animations`, ни
`provideAnimations()`. Движение отключается, когда операционная система просит сократить анимацию
(`prefers-reduced-motion: reduce`). Чтобы отключить его во всем приложении, например в end-to-end
тестах, предоставьте `KBQ_ANIMATIONS_CONFIG`:

```typescript
import { KBQ_ANIMATIONS_CONFIG } from '@koobiq/components/core';

bootstrapApplication(AppComponent, {
    providers: [{ provide: KBQ_ANIMATIONS_CONFIG, useValue: { animationsDisabled: true } }]
});
```

### Настройка стилей

После установки необходимо подключить стили библиотеки. Добавьте следующие файлы в массив `styles` вашего файла `angular.json`:

```json
"styles": [
  "node_modules/@koobiq/icons/fonts/kbq-icons.css",
  "node_modules/@koobiq/design-tokens/web/css-tokens.css",
  "node_modules/@koobiq/design-tokens/web/css-tokens-light.css",
  "node_modules/@koobiq/components/prebuilt-themes/theme.css",
  "src/styles.css"
]
```

Токены code-block, scrollbar и skeleton поставляются отдельными файлами, подключаемыми по желанию.
При обычном подключении делать ничего не нужно: их значения уже входят в `prebuilt-themes/theme.css`,
файл собирается вместе с библиотекой. Отдельно эти файлы нужны только если вы собираете стили
библиотеки сами из SCSS-исходников:

```scss
@use '@koobiq/design-tokens/web/component-tokens';
@use '@koobiq/design-tokens/web/component-tokens-light';
@use '@koobiq/design-tokens/web/component-tokens-dark';
```

Чтобы поменять значения по умолчанию, подключать файлы не нужно — просто задайте нужные
CSS-переменные в своих стилях, см. [руководство по темам](/ru/main/theming/overview).

### Настройка темы

Добавьте классы темы к элементу `<body>` в файле `index.html`: `kbq-app-background` задаёт фон и цвет текста
страницы, `kbq-light` выбирает тему.

```html
<body class="kbq-app-background kbq-light">
    <app-root></app-root>
</body>
```

Для тёмной темы или переключения тем добавьте в стили и `css-tokens-dark.css`; подробнее читайте в разделе
[темизация](/ru/main/theming).

### Настройка локали

Часть строк компоненты выводят сами: плейсхолдеры, подсказки, доступные имена кнопок-иконок. Пока приложение не
задало локаль, они берут строки `ru-RU`, а переключение локали во время работы ничего не меняет. Задайте локаль
приложения:

```typescript
import { kbqLocaleIDProvider, kbqLocaleServiceProvider } from '@koobiq/components/core';

bootstrapApplication(AppComponent, {
    providers: [kbqLocaleIDProvider('ru-RU'), kbqLocaleServiceProvider()]
});
```

Если в приложении есть компоненты для работы с датами, подключите адаптер дат в тех же `providers`: тогда один
сервис локали обслуживает и компоненты, и адаптер, и локаль, переключённая во время работы, доходит до обоих.

```typescript
import { importProvidersFrom } from '@angular/core';
import { KbqLuxonDateModule } from '@koobiq/angular-luxon-adapter/adapter';

bootstrapApplication(AppComponent, {
    providers: [kbqLocaleIDProvider('ru-RU'), kbqLocaleServiceProvider(), importProvidersFrom(KbqLuxonDateModule)]
});
```

Библиотека поставляет `en-US`, `es-LA`, `pt-BR`, `ru-RU` и `tk-TM`. Как переключать локаль во время работы и
переопределять строки, читайте в разделе [локализация](/ru/main/localization).

Подробнее читайте в разделе [типографика](/ru/main/typography).

### Использование компонента

Добавьте компонент в ваше приложение, чтобы убедиться, что всё работает корректно.

```typescript
import { KbqButtonModule } from '@koobiq/components/button';
import { KbqIconModule } from '@koobiq/components/icon';

@Component({
    imports: [KbqButtonModule, KbqIconModule],
    template: `
        <button kbq-button>
            <i kbq-icon="kbq-plus_16"></i>
            Кнопка
        </button>
    `
})
export class AppComponent {}
```
