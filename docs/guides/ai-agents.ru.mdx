Koobiq поставляет навык для AI-агентов, чтобы Claude Code, Codex, Copilot, Cursor и другие агенты собирали интерфейсы из компонентов Koobiq, а не угадывали.

С навыком агент импортирует из нужных точек входа, стилизует через дизайн-токены и следует примерам из документации.

### Что входит в пакет

В `@koobiq/components` для агентов есть две вещи, которые собираются из этой документации к каждому релизу:

- `skills/koobiq-angular` - сам навык: правила, карта всех компонентов и короткие руководства по выбору между похожими компонентами, темизации, формам, иконкам, локализации и SSR. Навык написан в открытом формате [Agent Skills](https://agentskills.io).
- `agent-docs` - справочники для установленной версии: обзор каждого компонента с полным кодом его примеров, входы, выходы и дизайн-токены, руководства и список миграций. Агенты читают их на месте, из `node_modules`, поэтому справочники всегда совпадают с версией, которая стоит в проекте.

И то и другое - обычные файлы внутри пакета: при настройке ничего не отправляется по сети.

### Настройка

В проекте на Angular CLI запустите схематик и выберите агентов:

```bash
ng generate @koobiq/components:agent-skills
```

Или передайте агентов сразу:

```bash
ng generate @koobiq/components:agent-skills --agents=claude-code,codex
```

`ng add @koobiq/components` задаёт тот же вопрос при установке. Если не выбрать ни одного агента, ничего не настраивается.

Схематик:

- копирует навык в `.claude/skills/koobiq-angular` для Claude Code и в `.agents/skills/koobiq-angular` для остальных агентов;
- добавляет короткий блок правил в `AGENTS.md`, а также в `CLAUDE.md`, если тот не импортирует `AGENTS.md`. Агенты загружают эти файлы при каждом запросе, поэтому обращаются к навыку, даже если сами бы его не выбрали. Блок стоит между маркерами `<!-- koobiq:agent-rules:start -->` и `<!-- koobiq:agent-rules:end -->`, текст вне маркеров никогда не меняется. Чтобы не добавлять блок, передайте `--instructions=false`.

Добавьте эти файлы в репозиторий: тогда вся команда и агенты в CI работают с одной и той же настройкой.

#### Без Angular CLI

Скопируйте папку `node_modules/@koobiq/components/skills/koobiq-angular` в папку навыков своего агента или установите её утилитой [skills](https://github.com/vercel-labs/skills):

```bash
npx skills add ./node_modules/@koobiq/components/skills/koobiq-angular
```

Та же утилита ставит навык последнего релиза прямо с этого сайта. Это удобно для проекта, который ещё не зависит от `@koobiq/components`:

```bash
npx skills add https://koobiq.io
```

### Обновление

Навык привязан к версии пакета. После обновления `@koobiq/components` запустите схематик ещё раз: он заменит файлы, которые установил сам, сохранит те, что вы меняли, и перечислит их в выводе. Чтобы заменить и их, добавьте `--force`. При переходе на новую мажорную версию `ng update @koobiq/components` обновляет установленный навык сам.

Справочники в `node_modules/@koobiq/components/agent-docs` обновлять не нужно: они приходят вместе с пакетом.

### Когда агент находит пробел

Навык просит агента прямо сообщать, если для задачи не нашлось подходящего компонента Koobiq или пришлось переопределить стили компонента либо жёстко прописать значение. Такие сообщения помогают развивать дизайн-систему: [создайте issue](https://github.com/koobiq/angular-components/issues) с задачей и тем, что агент сделал вместо этого.

### Документация для агентов, которые читают веб

Справочники из `agent-docs` опубликованы на этом сайте в виде Markdown, по файлу на страницу: например, [agent-docs/components/button.md](https://koobiq.io/agent-docs/components/button.md), а оглавление лежит в [agent-docs/README.md](https://koobiq.io/agent-docs/README.md). Документация также доступна в формате llms.txt: в [llms.txt](https://koobiq.io/llms.txt) перечислены страницы, а в [llms-full.txt](https://koobiq.io/llms-full.txt) лежит их полный текст.
