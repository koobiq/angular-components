# 11. Гайд по точечной кастомизации, когда токена нет

**Приоритет:** P3 · **Где:** docs · **PR:** `docs: describe how to restyle a component part that has no token`

> Из разбора внешнего отзыва об использовании UI-кита. Состояние на 2026-10-08, `main` @ `7c3761794`.
> Все задачи — в [README](README.md).

**Проблема.** Темизация описывает переопределение через токены: класс на экземпляре или селектор темы для всех. Что делать,
если у внутреннего элемента токена нет, не описано, и команды делают кто во что горазд: `::ng-deep`, `!important`,
усложнённые селекторы.

**Что описать** (раздел в темизации, EN и RU):

- рекомендуемый способ: свой класс на хосте компонента и правило в глобальном файле стилей, подключённом после стилей
  дизайн-системы (компоненты используют `ViewEncapsulation.None`, поэтому `::ng-deep` не нужен);
- что считается стабильным API (токены, документированные классы), а что может поменяться в минорной версии
  (внутренние BEM-классы);
- как попросить новый токен (issue).
