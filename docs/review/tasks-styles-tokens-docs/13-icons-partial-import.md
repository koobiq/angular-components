# 13. Иконки: подключение не целиком

**Приоритет:** P3 · **Где:** репозиторий `koobiq/icons`

> Из разбора внешнего отзыва об использовании UI-кита. Состояние на 2026-10-08, `main` @ `7c3761794`.
> Все задачи — в [README](README.md).

**Проблема.** `@koobiq/icons/fonts/kbq-icons.css` весит 148 КБ (94 КБ сжатый) и содержит 1173 класса иконок плюс шрифт;
подключается только целиком. В Shadow DOM классы иконок нужно доставлять в каждый shadow root (dev-стенд
`packages/components-dev/icon-adopted-stylesheets`, DS-5207).

**Что сделать.** Рассмотреть поставку подмножества или по одной иконке (SVG-спрайт, SVG-компонент), описать вариант для MFE
в гайде из [задачи 10](10-mfe-guide.md).
