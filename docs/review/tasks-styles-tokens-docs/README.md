## Что в отзыве не подтвердилось

- **«Нет инструкции по установке»** — есть гайд по установке, `ng add`, гайд по темизации, шрифты в «Типографике»
  (Fontsource или CDN), иконки на странице icon. Проблема в противоречиях между ними ([задача 3](03-docs-styles-setup.md)).
- **`koobiq.io/assets/stackblitz/src/styles.scss`** — не утечка: это шаблон, который сайт загружает, чтобы открыть пример
  в StackBlitz (`apps/docs/src/app/components/stackblitz/stackblitz-writer.ts:17`).
- **«Компоненты дублируют шрифтовые токены»** — библиотека их уже не читает: компоненты берут глобальные типографические
  уровни (175 мест). 830 переменных у проекта — это устаревший `css-tokens-font.css`, который можно просто не подключать.
- **«Константы в CSS-переменных», кроме палитры** — это 15 размеров; переносить их в SCSS нет смысла.
