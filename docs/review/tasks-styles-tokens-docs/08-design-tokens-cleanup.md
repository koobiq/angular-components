# 8. Чистка пакета токенов

**Приоритет:** P2 · **Где:** репозиторий `koobiq/design-tokens`

> Из разбора внешнего отзыва об использовании UI-кита. Состояние на 2026-10-08, `main` @ `7c3761794`.
> Все задачи — в [README](README.md).

**Проблема.**

- В `css/typography.css` 45 типографических уровней, и у каждого стек шрифтов записан строкой, а не
  `var(--kbq-font-family-base|accent|mono)`. Смена шрифта — 45 правок вместо одной.
- `css-tokens-font.css` (830 переменных) и компонентные токены в `css-tokens*.css` (469 в `:root` и около 1020 на каждую
  тему) помечены DEPRECATED, но лежат в файлах, которые потребителям велено подключать.
- В старом наборе нет 29 токенов из `web/new` ([задача 1](01-opacity-overlay-fallback.md)), а палитра дублируется (`--kbq-palette-*` и `--kbq-plt-*`).
- Палитра входит в «набор по умолчанию» (`web/new/css-tokens.css`, `index.bundled.css`), хотя темам она не нужна.

**Что сделать.**

- Шрифтовые свойства уровней — через переменные семейств.
- В 4.0.0 удалить компонентные токены и старый набор; до этого — явное предупреждение в README пакета.
- Вынести палитру из набора по умолчанию в отдельный подключаемый файл.
